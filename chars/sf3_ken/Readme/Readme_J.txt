ケン (Street Fighter III 3rd strike/ IV)
最終更新日時：2018月2月12日
完成度：99%

リュウの永遠のライバルケン。3rdの３強の一人。（もう二人はユン、春麗）ただし、他の２人よりもSAの脅威（ダメージ）が少ないため、ランクで言えば３番目となります。

トゥエルヴの付属品のケンを単体版にしたものです。違いはSFIV仕様が追加されたこと、食らいモーションをケンのものにしたことです。
食らいモーションはデフォルトのもの以外に3rd固有の立ち食らい5種類、空中吹き飛びが2種類あります。

ラウンド開始時にSF IV・SSF IVかSFIII3rd・SFIII2nd・SFIII1stの選択が出来ます。
また、SFIIIではコマンド仕様を3rdか2ndどちらか選択が出来ます。
1st,2nd性能の基本システムはほぼ3rdですがガードブロッキングがありません。

コマンド仕様は投げ及びリープアタックのコマンドの変化です。
投げは2nd仕様の場合1F投げになり間合いが狭くなります。
リープは2nd仕様の場合ダメージ・スタン値・ゲージ増加量が上がります(2ndモード時は2ndコマンド仕様で原作と同等の性能)。

投　げ：2nd　レバー入れ中・強攻撃　3rd　弱P弱K同時押し
リープ：2nd　22+PorK		　 　3rd　中P中K同時押し


スーパーアーツは試合開始時に３種類中から１つ選んでください。
また、ラウンド開始前にStartボタン押すことで全てのスーパーアーツ（SA）を使用することも可能です。(ゲージの長さ：128*2)
原作とは違い、ダメージ・無敵時間を調整しております（96*2の性能）。

ゲージの長さ

SAI	:昇竜烈破	(112*2)(1stのみ(104*2))
SAII	:神龍拳	(104*1)(1stのみ(112*2))
SAIII	:疾風迅雷脚	(80*2)


原作との相違点
・昇竜烈破は初段が当たったらその後の攻撃はほぼ全て当たるように。
・疾風迅雷脚は原作の３本ではなく、1stのように２本に（性能・威力は変化なし）。
・1st性能でもEX技・PAが使えるように。
・1st,2ndの特殊技は原作の6+中と違い、3rdと同じ4+中Kに。
・ALL SA選択時は各SAのダメージをゲージ量・ストック本数を基に調整しています（原作はダメージ変化なし）。

====SFIV仕様===
下半身飛び道具無敵など体の一部分のみが部分無敵はMUGENでは再現不可能なので設定されていません。

6中K空振りキャンセルすると投げ・セービングが少し移動して出せます。

スーパーコンボ：昇竜烈破	ゲージ全消費。
ウルトラコンボ：神龍拳		被ダメージで増加するリベンジゲージ全消費。消費量により攻撃力が変化。キャンセルで出せない。

ウルトラコンボはボタン３つ同時押しで出すのでキーボードだと入力できない場合があります。
sf3_ken.cmdファイルのvar(58)&&command="Reppa"&&command="x"&&command="y"&&command="z"をvar(58)&&command="Reppa"&&(command="xy"||command="yz"||command="xz")
に変えれば２つ同時押しに変更されます。
