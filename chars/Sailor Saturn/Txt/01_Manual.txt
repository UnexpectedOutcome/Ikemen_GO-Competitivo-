            各設定変更
*************************************************************************************
◆.AILv調節方法

 saturn.cmd.cns の [State -1, AIフラグセット] を検索し

 var(59)  = 10;10 ← ;より左の10を1～10までの値に変更。


◆.アクション顔画像表示有無変更方法

 saturn.cns の [State -2, 表示スイッチ] を検索し

 value    = 1;表示 ON(1)/OFF(0) ← ;より左の1を0～1までの値に変更。


◆.アクション顔画像表示位置変更方法

 Helper.cns の [State 9○5, アクション顔画像 x/y座標] を検索し
 (○;数字)

[State 9○5, アクション顔画像 x座標]
type     = varset
trigger1 = 1
v        = 47
value    = 1;この値を弄ればOK

[State 9○5, アクション顔画像 y座標]
type     = varset
trigger1 = 1
v        = 48
value    = 18;この値を弄ればOK

「この値を弄ればOK」より左の数値を弄ればOK
ただし、1Pシングル・1Pタッグ後衛・2Pシングル・2Pタッグ後衛の4つがあるため注意


◆.ボイス変更方法

 saturn.cns の [State -2, 皆口裕子/石川由依 ボイスチェンジスイッチ] を検索し

 value    = 0;皆口裕子(0)/石川由依(1) ← ;より左の1を0～1までの値に変更。
