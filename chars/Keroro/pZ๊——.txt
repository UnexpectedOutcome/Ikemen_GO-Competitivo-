　　　最初に読んどいたほうがいいかもですよ。

　・特技15種

・魔神剣　　　　　　　　　　　　　　　D,F + a
　　　　言わずと知れた基本技にしてアルベイン流最終奥義。
　　　　クレスは子供の頃から使えたらしい(今も子供だが)
　　　　なのにトリスタン師匠が言うには｢大器晩成型｣。末恐ろしい。
　　　　射程無限の地を這う衝撃波を出します。剣の振りにも判定あり。
　　　　相手との距離が離れたら連発しよう。
　　　　そう言えばどっかの英雄志願者がどっかでディスってた。
　　　　この技のみ同技キャンセルが不可能です。

・飛燕連脚　　　　　　　　　　　　　　D,B + a
　　　　ジャンプしながらの二段蹴りから剣で突き刺す技。
　　　　重力から解き放たれるおかしい技。
　　　　物理法則を無視してます。
　　　　空中発動可能。世界の法則が乱れる。
　　　　2回目の蹴りから空中技に連携可能。
　　　　空中連携中は1回しか出せません

・襲爪雷斬　　　　　　　　　　　　　　b
　　　　ジャンプ切り上げ→謎の雷弾を放つ
　　　　→物体が当たると落雷→切りおろす。
　　　　な技。どうやって謎の物体を出したり
　　　　落雷を発生させてるのかは不明。
　　　　未来永劫解明されないでしょう。
　　　　最近のシリーズじゃまともに出せないシロモノ。
　　　　雷弾の部分はガード不可能。

・秋沙雨　　　　　　　　　　　　　　　x
　　　　作品によって最後の〆が安定しない10連突き。
　　　　原作ではノロノロ運転+攻撃判定が
　　　　存在しない突きもある何かと問題のある技。
　　　　マイソロ並みのスピードになっております。

・虎牙破斬　　　　　　　　　　　　　　D + x
　　　　ジャンプ切り上げ、切りおろしな技。
　　　　2HITずつするのはPS版仕様。
　　　　リアルでやろうとすると意外と
　　　　難しい技の一つ。特に2HITさせるところが。
　　　　空中発動可能。

・鳳凰天駆　　　　　　　　　　　　　　c
　　　　炎を纏い斜め上に飛び上がり急降下する技。
　　　　クレス自身が火の鳥になることはもうありません。たぶん。
　　　　攻撃しながらの移動手段として非常に優秀です。是非お試しを。
　　　　空中発動可能。距離を置いていたら急襲に使えます。
　　　　特定の状況下で放つと3割以上持っていきやがります。
　　　　方法は探してみてください。

・守護方陣　　　　　　　　　　　　　　D,D + x
　　　　剣を地面に突き立て魔法陣を展開。
　　　　魔法陣から聖なる何かが飛んでいきます。
　　　　かなり高くまで判定が存在するので
　　　　飛び回る相手への牽制に使えそう。
　　　　でもHPは回復しない。

・真空破斬　　　　　　　　　　　　　　F + x
　　　　力を溜めて渾身の一撃を放つ技。
　　　　タメ部分が長いけど威力はピカイチっす。
　　　　攻撃範囲も広いっす。
　　　　単発だと使いにくいので連携の〆に。

・獅子戦吼　　　　　　　　　　　　　　y
　　　　ライオンみたいな衝撃波を出す技。グァオー
　　　　タックル→獅子の半PS仕様です。
　　　　相手は吹っ飛びます。
　　　　こちらも連携の〆に。

・閃空裂破　　　　　　　　　　　　　　B + x
　　　　読みは「せんくうれつは」。「せんくうれっぱ」ではない。
　　　　アッパーで敵を打ち上げジャンプ突きで追撃。
　　　　動作後いろんな空中技に繋げてしまおう。
　　　　ガードされると反撃確定な諸刃の剣。
　　　　一番モーションが変わった技。

・紅蓮剣　　　　　　　　　　　　　　　D,DF,F + x
　　　　敵を突き上げ火炎車みたいなものを放つ技。
　　　　なんで炎出せたり雷発生させたりできるのかは
　　　　依然不明。おそらく一生不明。
　　　　空中発動可能。相手との距離があれば牽制にでも。
　　　　爆発部分はガード不可能。

・虚空蒼破斬　　　　　　　　　　　　　z
　　　　チート剣技その1。
　　　　周囲を回転しつつ上昇する光弾を出した後、
　　　　前方に蒼い衝撃波状の闘気を放つ技。
　　　　って、テイルズオブ用語辞典に書いてあった。
　　　　攻防一体の優秀な技だそうです。まぁそうですけど。

・空間翔転移　　　　　　　　　　　　　B + z
　　　　チート剣技その2。
　　　　足元から立ち昇る光弾で攻撃しながら
　　　　目標の頭上に瞬間移動。下突き、回し蹴り、
　　　　下段突き、突き上げの連続攻撃をお見舞する技。
　　　　相手との距離を考えずに強襲できます。
　　　　非常に優秀で使い勝手がいい技・・・なのか？
　　　　原作のラスト以外が結構かっこよかったので
　　　　ラストだけアレンジ。元の位置には戻りません。

・次元斬　　　　　　　　　　　　　　　D + z
　　　　チート剣技その3。
　　　　自分の周りにドーム状の空間を作りながら
　　　　ジャンプ切り、斬りおろしを見舞う技。
　　　　リーチは飛び道具技を除けば全技トップ。発生も早い。
　　　　攻撃判定が出る直前まで無敵。
　　　　ぶっちゃけ性能おかしい。でもそれがいい。
　　　　文句は受け付けるけど改善はしない予定。

・飛連閃　　　　　　　　　　　　　　　F + z
　　　　原作なりダンXより追加された技。
　　　　斬り下ろしから突き上げ、その軌跡でVの字を描く瞬速の剣技。
　　　　とカッコよさそうな説明なのだが、単なるジャンプ切り→突き上げと
　　　　イマイチぱっとしない性能。特筆すべき点も無く･･･
　　　　こんなのでいいのか新技。
　　　　空中発動可。飛燕連脚より少しだけクセがありますが、
　　　　空中コンボの中継技にうってつけです。

　・特殊技2種

・集気法　　　　　　　　　　　　　　　a + x
　　　　2秒半の間集中することで
　　　　体力を回復する特殊技。
　　　　回復量は最大Lifeの20%
　　　　通常攻撃等からのキャンセルが不可能。

・剛招来　　　　　　　　　　　　　　　a + y
　　　　10秒の間、コンボ補正を大幅に緩和する特殊技。
　　　　重ね掛けはできても効果は重複しません。
　　　　技を発動させたときに超短射程の攻撃判定が
　　　　出現し、微量のダメージを与えます。ガード不能。
　　　　密着してからどうぞ。
　　　　この技のみキャンセラーの制約を受けません。
　　　　特技、特技、剛招来、奥義・・・の連携が可能に。

　・奥義12種

・魔神双破斬　　　　　　　　　　　　　D,F,D,F + a
　　　　魔神剣+虎牙破斬×2な技。
　　　　虎牙破斬のラストにダウン効果アリ。
　　　　超メジャーだと思ってたのにどっかの動画で
　　　　マイナーって言われててかなり凹んだ思い出がありますのよ。
　　　　確かに最近じゃ影に潜み始めてるけど。

・魔神千裂破　　　　　　　　　　　　　F,D,B + a
　　　　連続突きのあとに、地面を這う衝撃波を放つ。 
　　　　つまり秋沙雨→魔神剣の連携。
　　　　あまりクセが無く使いやすいと思います。
　　　　拘束時間が長めとタッグ向けな技かも。

・獅子吼破斬　　　　　　　　　　　　　D,F,D,F + y
　　　　斬り上げ斬り下ろしの連続攻撃から、
　　　　獅子の闘気をぶつけ敵を吹き飛ばす技。 
　　　　つまり虎牙破斬→獅子戦吼の連携。
　　　　最後に相手を叩きつけます。
　　　　こちらもあまりクセが無く使いやすいです。

・獅子千裂破　　　　　　　　　　　　　F,D,B + y
　　　　読みは「ししせんれつは」
　　　　秋沙雨+獅子戦吼の奥義。
　　　　こちらも拘束時間が長めです。
　　　　最後に相手を叩きつけます。
　　　　HIT数が多く、補正をまともに受けるので
　　　　剛招来とセットでお楽しみください。

・襲爪飛燕脚　　　　　　　　　　　　　D,DF,F + b
　　　　襲爪雷斬をキメた相手に追撃の飛燕連脚で
　　　　ダメージが更に加速する奥義。
　　　　つまり襲爪雷斬→飛燕連脚の連携。
　　　　あたらなさそうに見えて意外とあたる技。

・襲爪閃空破　　　　　　　　　　　　　D,DB,B + b
　　　　闘気を放ち敵を打ち上げてから、
　　　　斬り上げて雷弾を放ち、落雷と同時に斬り下ろす技。
　　　　つまり閃空裂破→襲爪雷斬の連携。
　　　　雷部分はガード不可です。

・鳳凰天翔脚　　　　　　　　　　　　　D,D + c
　　　　空中連続蹴りを放ち､鳳凰天駆で突進する。 
　　　　つまりは飛燕連脚→鳳凰天駆の連携。 
　　　　ただでさえ出の早い鳳凰天駆系の中では
　　　　特に出が早く、非常に使い勝手がいい。
　　　　似た技に鳳凰天翔駆とか皇王天翔翼とか
　　　　鳳翼天翔とかあってめっさ紛らわしい。
　　　　まぁ最後のはコスモが云々な技だけど。
　　　　空中発動可能。連携の〆にしてさらに
　　　　緋凰絶炎衝につなげるのもアリ。

・鳳凰翔破斬　　　　　　　　　　　　　D,DF,F + c
　　　　炎を纏って飛び上がり敵に突撃し、
　　　　さらに斬り上げ、斬り下ろしを2回連続で行う。
　　　　動作的には鳳凰天駆で敵の後ろに回り、
　　　　使用後は必ず後ろに振り向いて虎牙破斬で斬りつける。
　　　　つまり鳳凰天駆→虎牙破斬の連携。
　　　　鳳凰天駆で相手の背後を取れなくても
　　　　振り向いてしまうのはご愛嬌。
　　　　まぁそうそう背後が取れないことは無いんだけど。
　　　　空中発動可能です。

・鳳凰天空破　　　　　　　　　　　　　D,DB,B + c
　　　　炎を纏って飛び上がり、着地と同時に
　　　　闘気を巻き上げて攻撃する技。
　　　　つまり鳳凰天駆→閃空裂破の連携。
　　　　なお、閃空裂破部分は敵がいる方向ではなく、
　　　　自分が元居た方向に向けて放たれる。
　　　　つまり、鳳凰天駆で相手の裏に回れなければ、
　　　　あらぬ方向に向けて闘気を放出することになる。
　　　　･･･以上用語辞典からのコピペでした。

・時空蒼破斬　　　　　　　　　　　　　D,DF,F + z
　　　　時空剣技の一つ。次元斬＋虚空蒼破斬の合わせ技。
　　　　次元斬で攻撃した後､虚空蒼破斬と同じ闘気を放ちます。
　　　　範囲がおかしいのはいわずもがな。
　　　　原作では次元斬と虚空蒼破斬の間に若干隙があったけど
　　　　コイツはそこまでございません。優遇です。技の差別です。
　　　　ただガードされているとどうなるかは知りません。

・転移蒼破斬　　　　　　　　　　　　　D,DB,B + z
　　　　時空剣技の一つ。空間翔転移＋虚空蒼破斬の合わせ技。
　　　　空間翔転移と同様の光弾で攻撃し、
　　　　敵の頭上に瞬間移動して下突き、蹴り、
　　　　虚空蒼破斬と同様の闘気を放ちます。
　　　　相手との間合いに関係なく転移し､
　　　　虚空蒼破斬を浴びせる強力な時空剣技。
　　　　ガードされても削れますので、その辺も考慮ください。

・猛虎連撃破　　　　　　　　　　　　　D,DB,B, + x
　　　　永遠と絆の主人公から盗んだ。もとい借りてきた。
　　　　GBA版のみ習得可能な珍しい技。
　　　　上下8段となる斬り上げと斬り下ろしを繰り出す。
　　　　攻撃時間がとっても長いです。
　　　　外れればすっげぇ隙になりますけど。まず外れることは無いです。
　　　　うん百回繰り返しても敵のLifeが2000以下でも
　　　　龍虎滅牙斬には繋がりません。
　　　　最後の1撃で相手を叩きつけます。
