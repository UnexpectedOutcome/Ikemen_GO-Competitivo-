キュアハッピー（ストライカー搭載版）
------------------

　●「スマイルプリキュア！」より、主人公のキュアハッピーです。
　　製作途中で、調整不足なところもあると思いますが、楽しんでいただけたら幸いです。

　●WIN版専用キャラです。

カラーについて
--------------
キャラ選択時に押したボタンによりカラーが変わります。（能力は全て同じです）
・aボタン：キュアハッピーカラー　
・bボタン：キュアサニーカラー
・cボタン：キュアピースカラー
・xボタン：キュアマーチカラー
・yボタン：キュアビューティカラー
・zボタン：キュアキャンディカラー
・startを押しながらa～zのいずれかのボタン：みゆきカラー


操作方法
--------
全て右向きの時の操作です。左向きは移動キーのみ左右逆の操作で行います。

    基本操作
    --------

      各ボタンの説明：
      D - 下
      F - 前
      U - 上
      B - 後
      x - Ｘボタン
      y - Ｙボタン
      z - Ｚボタン
      a - Ａボタン
      b - Ｂボタン
      c - Ｃボタン
      s - スタートボタン

      DFは斜め前下、UBは斜め後ろ上など、斜め入力はDFUBを２つ組み合わせる表記になっています。
      空中では、一回だけ空中ジャンプが可能です。
      空中受け身を出した瞬間、キーを左右どちらかに押していたら
      その方向に少し移動しながら受け身を取ります。
      横に倒れている時、ボタンを連打すれば起き上がりが速くなります。
      スタートボタンを押せば相手を挑発します。


    通常動作
    --------
      U              - ジャンプ
      UF             - 前ジャンプ
      F              - 前進
      DF             - しゃがむ
      D              - しゃがむ
      DB             - しゃがみ＆しゃがみガード
      B              - 後退＆ガード（空中では空中ガード）
      UB             - 後ジャンプ
      F, F           - ダッシュ
      B, B           - バックステップ
      xy             - 空中受け身

    特殊動作
    --------
      Ａ＋Ｘボタンを押しっぱなし -「気合だ！気合だ！気合だ～～～！！」
                                   :ライフを消費して、パワーゲージを急速に上昇させます。
                                   :この動作でライフが0になることはありません。

      Ｚボタン（空中でも可能）   - シールド

      (空中で)F, F               - エアダッシュ(ちょうちょデコル)

      (空中で)B, B               - エアバックダッシュ(ちょうちょデコル)
　

    立ち通常攻撃
    ------------
      X              - 弱パンチ
      Y              - 強パンチ
      A              - 弱キック
      B              - 強キック

    しゃがみ通常攻撃
    ----------------
      X              - しゃがみ弱パンチ
      Y              - しゃがみ強パンチ
      A              - しゃがみ弱キック
      B              - 足払い

    ジャンプ通常攻撃
    ----------------
      X              - ジャンプ弱パンチ
      Y              - ジャンプ強パンチ
      A              - ジャンプ弱キック
      B              - ジャンプ強キック

    投げ
    ----
      F/B + y (密着して) - 投げ

    必殺技
    ------
      D, DB, B + x   - ダッシュパンチ・弱
      D, DB, B + y   - ダッシュパンチ・強
      D, DB, B + xy  - ダッシュパンチ・EX :(パワーゲージを330ポイント消費)

     (空中で)D, DB, B + a   - 空中急降下キック・弱
     (空中で)D, DB, B + b   - 空中急降下キック・強
     (空中で)D, DB, B + ab  - 空中急降下キック・EX:(パワーゲージを330ポイント消費)

      D, DF, F + x/y -ハッピービーム

      D, DF, F + a   - 弱・蹴り上げ    :中段攻撃
      D, DF, F + b   - 強・蹴り上げ　　:中段攻撃
      D, DF, F + ab  - 速い蹴り上げ 　 :中段攻撃(パワーゲージを330ポイント消費)

      F, D, DF + a   - 弱・上昇蹴り
      F, D, DF + b   - 強・上昇蹴り
      F, D, DF + ab  - 速い上昇蹴り　　:(パワーゲージを330ポイント消費)
      飛んでる最中にＡかＢを押せば追加攻撃が可能

      D, DB, B + a/b - 急降下キック

    超必殺技
    --------
　　○Lv．1（パワーゲージを1000ポイント消費）
      a+c　　　- ハッピービーム・EX
      D, DF, F, D, DF, F + x/y　または F+a+c  - ハッピーラッシュ
      D, DB, B, D, DB, B + x/y　または B+a+c  - 強い蹴り上げ　;中段攻撃

　　○Lv．2（パワーゲージを2000ポイント消費）
　　　b+c　　　- プリキュアハッピーシャワー

    ストライカー
    ------------
　　○キュアサニー
      c        - サニーファイヤーパンチ          :(パワーゲージを500ポイント消費)

　　○キュアピース
      F+c      - ピース100億ボルトブレイク       :(パワーゲージを500ポイント消費)

　　○キュアマーチ
      B+c      - マーチウインドキック            :(パワーゲージを500ポイント消費)

　　○キュアビューティ
      D+c      - ビューティダイヤモンドブレス    :(パワーゲージを500ポイント消費)

【改変等について】
　　個人で遊ぶ範囲ならば改変はご自由にして頂いて大丈夫です。

　　ただし改変したキャラを公開、このキャラの転載等はしないでください。

　  AIパッチに関しては自由に公開していただいてかまいません。
 （もし公開される場合は、BBSに一言頂けるとありがたいです。）

【動画使用について】
　　動画使用は大丈夫です。
    ですが、常識の範囲内でのご使用をお願いします。

    大会動画やストーリ動画などでは仕方ありませんが、それ以外の動画での一方的な試合
    (特に、特定のキャラを虐待目的で対戦させるような試合)などで、
    対戦相手のキャラの製作者様が気分を害されるような動画には使用しないで下さい。

    …少し強めに書いてしまいましたが、実際にあったことで、
    対戦相手のキャラの製作者様が気分を害されてしまい、私も心苦しかったです。
    
    ですが、上記の内容を守って頂けるのでしたら、お気軽に動画に使用してあげて下さい。
