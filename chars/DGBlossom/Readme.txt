DG Blossom by DoomGuy II
------------------------

This is an edit of OmegaPsycho's Blossom. She includes new and improved
animation, new sprites, new sounds, new and improved
normal moves, new and improved specials, and new and
improved supers.

This character is for Mugen v1.0 only.

Any questions or comments, find me on Youtube: http://www.youtube.com/user/DoomGuy2nd

-----
Moves
-----

Normal
------

F = move forward
B = move back
U = Jump
D = Duck
a = low kick
b = high kick
x = low punch
y = high punch
z = dodge (back = B, z) (forward = F, z)

-Sweep Kick: B, a

-Roundhouse Kick: B, b

-Combo 1: b,a,x,y

-Combo 2: y,x,a,b,y

-Air Combo 1: b,a,x,y,b

-Air Combo 2: y,x,a,b,y


Specials
--------

-Laser Eyes (also in air): D, F, y

-Diagonal Laser Eyes: D, B, x

-Dash: D, B, x

-Super Dash: D, B, y

-Ice Blast (also in air): D, DF, F, b

-Diagonal Ice Blast: D, DB, B, b

-Ice Puddle: D, DB, B, a

-Aerial Uppercut: B, DB, B, x

-Super Aerial Uppercut: B, DB, B, y

-Harpoon: B, B, x

-Slide Kick: B, a+b

-Counters (while guarding): B, x or B, a


Supers
------

-Mega Laser Beam (Level 1): D, B, D, F, a

-Super Fist Combo (Level 1): D, F, D, B, x

-Maximum Blossom (Level 1): D, B, D, F, x

-Super Ice Breath (Level 2): D, B, D, F, b

-Electric Fingers (Level 2): D, F, D, B, y

-Lightning Beam (Level 3): D, DF, F, x+y

-Triple Lasers (Level 4): D, F, D, B, a+b

-Bio Force Rosa [BFR] (Level 4): D, DF, F, c+z
