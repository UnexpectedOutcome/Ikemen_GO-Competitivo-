[調整方法]
・Config.stでコンボ補正率とか超必殺技エフェクトとか調整できます。
・調整可能なものは以下の通りです。
  ・ボイス (MBAC / MBAA)
  ・特殊ガード (シールド / ブロッキング / ジャストディフェンス)
  ・蝶必殺技エフェクトの種類 (CVS2 SNK Groove / CAP Groove)
  ・特殊カラーの割り当て
  ・コンボ補正開始ヒット数
  ・コンボ補正率
  ・SuperPause時相手防御力補正
