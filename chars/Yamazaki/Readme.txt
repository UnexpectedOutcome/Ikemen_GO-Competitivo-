 3. MOVELIST

 Has all that good shit as always, like dodging, parrying, cancelling...

 [HEBI TSUKAI]
 COMMAND: {D, DB, B + (a or x or y)}

 [SABAKI NO AIKUCHI]
 COMMAND: {F, D, DF + (P)}

 [BAI GAESHI]
 COMMAND: {D, DF, F + (P)} (Fierce version counter attacks with a fireball)

 [SNAKE HAND]
 COMMAND: {B, D, DB, F + (P)}

 [BAKUDAN PACHIKI]
 COMMAND: {F, D, B, F + (P)}

 [SADO MAZO]
 COMMAND: {B, D, F + (K)} (Counter-attacks with a mini-drill)

 [SAND KICK]
 COMMAND: {F, D, DF + (K)}
 

 **SUPER MOVES**


 [GUILLOTINE] (Pressing both punches results in SDM version that consumes 2 bars)
 COMMAND: {D, DF, F, D, DF, F + (P)} (Can be cancelled from Drill SDM)

 [DRILL] (Pressing both punches results in SDM version that consumes 2 bars)
 COMMAND: {F, D, B, F, D, B + (P)} (Mash the buttons after Yamazaki uppercuts
                                    the opponent for different combinations)
 [MADNESS] (Consumes 2 bars)
 COMMAND: {D, DF, F, D, DF, F + (2K)}
