[このキャラクターについて]
元ネタは真・女神転生Ⅲ、受胎後の渋谷で友を待ち続ける健気な姿が人気を呼んだ堕天使です。
configファイルを設定する事で友であるフォルネウスのON/OFFを切り替え出来ます。
フォルネウスの有無により、プレスターン消費による動作が変化します。
ちなみに動きはオリジナルなので、元ネタからはかなりかけ離れてると思います（笑）

a　　　:頭突き（？）。接触時a、屈みa、立ちb、屈みb、立ちc、屈みcにつながります。【キャンセル可】

c      :パイルバンカー（？）単発威力の大きな攻撃です。カス当りだとダメージも低く相手硬直も短いです。【キャンセル不可】

↓a    :小足（？）。接触時屈みa、立ちb、屈みb、立ちc、屈みcにつながります。【キャンセル可】
↓b    :引っ掻き（？）相手を引き寄せます。接触時立ちc、屈みcにつながります。【キャンセル可】
↓c    :回転足払い。相手をダウンさせます。【キャンセル不可】

空中a  :踏みつけ。接触時相手を踏みつけてジャンプします。接触時空中b、空中cにつながります。

空中c  :触手（？）攻撃。五本足で連続攻撃します。
空中↓c:ドリル攻撃。空中から垂直降下します。

x      :【魔眼】全画面に食らい判定を出現させます。飛び道具破壊専用技。技中は飛び道具に対して無敵。
空中x  :【我慢】眼をつぶって我慢します。アーマー状態になりますがダメージは普通に通ります。

[コマンド技]
426a b c  :スピンしながら相手に体当たり。aで３回ヒット、bで４回ヒット、cで５回ヒット。ヒット数が増加すると技後の隙も増えます。

623a b c  :スピンしながら斜め上にジャンプ。a→b→cの順にヒット数、飛距離が増えますが、技後の隙も増えます。

24a b c   :跳躍後に追加入力で技が派生します。跳躍時にも攻撃判定あり。a→b→cの順で跳躍距離が増加します。
　　　　　:追加入力a→斜め下の地上に衝撃波発生。ダウン追い討ち可能
　　　　　:追加入力b→斜め上に回転しながら突撃。
　　　　　:追加入力c→斜め下に回転しながら突撃。入力時の高さが威力に比例。ダウン追い討ち可能。
　　　　　:追加入力x→着地時に足下に衝撃波発生。ダウン追い討ち可能。

空中623c+x:【流れ星】空中で炎に包まれ急降下します。地面着地時に火柱発生。ヒット時追撃可能。

624 c+x    :【ペトラアイ】暗転後30Fの出が遅い投げ技。ヒット時相手を石化させ連続攻撃を叩きこみます。

[ゲージ技（２ゲージ）]
2626 c+x   :【メギド】発生の遅い設置技。発動までかなり時間がかかりますが攻撃回数・拘束時間共にべらぼうです。

[ゲージ技（３ゲージ）]
2 c+x      :【テトラカーン】飛び道具以外の相手の攻撃を跳ね返すバリアを展開します。相手を捕まえるまで消えず、打撃・投げ無効になるので相手によっては詰むかも。

[特殊]
start       :【フォルネウス攻撃切り替え】フォルネウスON時のみ有効で、攻撃の種類を切り替えできます。
　　　　　　:上段攻撃→ダウン追い討ち可能の中段攻撃。名前に偽りあり。
　　　　　　:下段攻撃→ヒット時追い討ち可能な下段攻撃。
　　　　　　:防御不可→発動にかなり時間がかかる突進攻撃・防御不可。ただし壁に激突時フォルネウスのライフ半減。
　　　　　　:死門流氷→氷柱を呼び出して攻撃。これのみプレスターンを２消費。

a+b    　　 :【プレスターン】フォルネウスON時  フォルネウスが攻撃を行います
　　　　　　　　　　　　　　 フォルネウスOFF時 強制的に立ち状態に復帰します。コンボを繋げたり相手のコンボから抜けたりできます。
