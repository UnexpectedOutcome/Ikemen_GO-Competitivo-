===============================================
 ================翠星石======================= 
===============================================
双子で、蒼星石と共に「庭師」と呼ばれるローゼンメイデン。
夢の扉を開けたりすることができ、如雨露で「樹」に水をあげたりする。

敬語なのに口が悪い。だがそれがいい。

人見知りで人間嫌い。だがそれもいい。

普段悪口を言っていても、いざとなると仲間を庇う、とっても仲間思いなドール。
最後の対水銀燈戦では雛苺を抱くようにして戦っていた。間違いない。
他、いつもジュンを「チビ人間」だとか言っているが、ジュンがピンチになったり
すると「ジュン！」って呼ぶあたり、萌え死んでしまう。

漫画版ではジュンがミーディアムとなった。



[口癖]
「～ですぅ」。語尾に「です」をつける。最強。

[能力]
如雨露で水を出して、人の心に潤いを。
攻撃は、なんだか樹を出して攻撃するくらい？あまり戦闘では積極的に動けない？
樹はどちらかというと防御タイプ。

[人工精霊]
スィドリーム。基本的に如雨露を使うときにこっそり活躍している。
(如雨露の水を満たす）

投げ技//////////////////////////////////

●投げ　　　　　　　→ + x+y
(F + 2punch)
 地上での投げ技です。すれ違いざまにポットをぶつけます。





技////////////////////////////////////////////////////////////////////

●ダッシュ　　　　　　　→,→
●バックダッシュ　　　　←,←
●２段ジャンプ　　　　　ジャンプ中に↑
●スーパージャンプ　　　↓,↑
●リカバー　　　　　　　吹っ飛ばされた時 a～z どれかひとつ


●お菓子　 　       a + x
(a + x)
 ライフ回復＆パワーゲージを溜めることができます。




●庭師の如雨露　　    ↓→ + x
(D,DF,F + Punch)      ↓→ + y
 目の前に大きな樹を出して攻撃します。
一部の飛び道具を遮断できます。



●キィーーッ　　      xボタン連打
(PunchPunch,Punch,Punch…)
 両手を高速で上下させることにより、相手にダメージを与えます。



●カバン飛行    　　  空中で↓→ + x
(D,DF,F + Punch)      空中で↓→ + y
 カバンにのって体当たりします。



●捕獲せよですぅ  　　         ↓← + x
(D,DB,B + Punch)   　　        ↓← + y
 投げ縄です。ヒットすれば一定時間拘束できます。



●威圧  　　                   ↓↓ + x
(D,D + Punch)   　　           ↓↓ + y
 高エネルギーを発し、身の周りに攻撃判定を生みます。



●快転    　　                 空中で↓→ + a
(D,DF,F + Kick)                空中で↓→ + b
 素早く地面に着地します。一瞬無敵時間がありますが、信用しすぎないこと。
着地後もボタンを押し続けていれば、ジェイド・スパイクに繋がります。


●ジェイド・スパイク    　　   ↓→ + a
(D,DF,F + Kick)                ↓→ + b
 大きく蹴り上げる対空技です。威力は高いですが、隙も大きいです。




超必殺技(ゲージ使用)////////////////////////////////////////////////////


●音撃・フライパン      ↓← + x+y
(D,DB,B + 2Punch)
 画面ほぼ全体に攻撃判定。しゃがみガード以外のガードでは防げません。


●開眼　 　 　　          ↓← + a+b
(D,DB,B + 2Kick) 
 発動中はパワーゲージが減っていきます。
この効果が続いている間は、全ての通常攻撃を通常攻撃でキャンセルできるように
なります。また、強攻撃は一定確率でガード不可になります。
必殺技等は使えなくなります。解除するには同じコマンドです。
倒れると強制解除されます。


●威圧EX 　　　    　　↓↓ + x+y
(D,D + 2Punch) 
 より大きなエネルギーを発し、近くにいる敵に襲い掛かります。


●カバン飛行EX         ↓→ + x+y
(D,DF,F + 2Punch)
 技中は無敵です。たくさんの樹を出して攻撃します。


●ジェイド・スパイクEX    　　   ↓→ + a+b
(D,DF,F + 2Kick)
 パワーゲージが続く限り、繋げることもできます。


特殊能力////////////////////////////////////////////////////


●包丁生成能力
 起き上がり時に攻撃ボタンを押しっぱなしで、包丁を４本投げながら起き上がります。




極大奥義//////////////////////////////////////////////////////

●「ケンカはやめやがれです」
 画面一帯に複数の樹を発生させます。また、技中はライフが大きく回復します。
特定の条件を満たした時、発動します。
