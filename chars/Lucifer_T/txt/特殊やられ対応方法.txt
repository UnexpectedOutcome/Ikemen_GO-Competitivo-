
【ジャギ、ジャギメイリン投げやられ対応方法】

;------------------------------------------------------------------------------

・ジャギ（アフロン氏）　「投げ」（おい、そこに座れ）

※　記述をしなくても対応はしますが、イスが重なって表示されてしまいます。

“Jagi.cns”内の下記の記述箇所

[Statedef 801]内
～

[State explod];エフェクト
type = Explod
trigger1 = animelem = 4
anim = 802
id = 802
sprpriority = 3
postype = p1
pos = 0,0
bindtime = -1
supermove = 0
ignorehitpause = 0
removetime = 123
under = 0
scale = 0.5,0.5
;trans = addalpha
;alpha = 206,166

上記　trigger1 = animelem = 4のすぐ下の行に

trigger1 = numtarget
trigger1 = !(target,name = "Lucifer")

という2行の記述を追加してください。
記述をすると、ジャギ側で表示されるイスが表示されなくなり、ルシファー側のイスが表示されます。

;------------------------------------------------------------------------------

・ジャギ（Ts氏）　「投げ」（おい、そこに座れ）

※　記述をしなくても対応はしますが、イスが重なって表示されてしまいます。

“Jagi1.cns”内の下記の記述箇所

[Statedef 801]内
～

[State 801, 椅子①]
type           = Explod
trigger1       = AnimElem = 4
trigger1       = P2Name != "RAOH" && P2Name != "RAOH ATL"
trigger1       = P2Name != "THOUTHER"
trigger1       = P2Name != "Mr.HEART"
anim           = 802
pos            = 30, 10
postype        = p1
scale          = 0.5, 0.5
sprpriority    = -1
ownpal         = 1
bindtime       = -1
supermove      = 0
removetime     = 129
IgnoreHitPause = 0
Persistent     = 0



上記　trigger1       = P2Name != "Mr.HEART"　のすぐ下の行に

trigger1       = P2Name != "Lucifer"

という記述をしてください。
記述をすると、ジャギ側で表示されるイスが表示されなくなり、ルシファー側のイスが表示されます。

;------------------------------------------------------------------------------

bindtime       = -1
supermove      = 0

trigger1       = EnemyNear,name != "Lucifer"

という記述をしてください。
記述をすると、ジャギ側で表示されるイスが表示されなくなり、ルシファー側のイスが表示されます。
