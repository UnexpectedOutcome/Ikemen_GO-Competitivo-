Tiny Rabbit "Fluffy"
ちびうさぎフラッフィ。
辺境一の技術をもつ爆弾職人（13才♀）。
愛用のハンドガン"Teacup"を片手に、厳しい辺境の世界を生きぬいている。
中の人など居ない。

オリジナルキャラクターです。
某有名ゲームのキャラクターのパロディでもありますが。

◆はじめに
ダウンロードありがとうございます。
MUGEN用キャラクター、Tiny Rabbitです。
winMUGEN（M.U.G.E.N Private beta test 2006.08.31e-D4）を基準に製作をしました。
動作テストはM.U.G.E.N 1.0のwin互換モードで行っています。
ワイド画面（画面800*480,キャラクターおよびステージのlocalcoord = 400,240）での使用でも基本的に問題ないと思います。
M.U.G.E.N 1.1で拡大縮小するステージを使うさいは、画面固定ヘルパーを出さない設定にした方がいいかもしれません。
（詳しくは下部◇本体設定項目をごらんください）

◆解説

◆特殊ゲージ「月齢」について
　　※画面上部にある月の画像は月齢をあらわしています。
　　※月は特定の条件で敵に攻撃をあてると満ち、満月になると真必殺技「エクストリームランアウェイ」を使うことができるようになります。
　　※月の満ち欠けは以下の条件でおこります。
　　　　◇満ちる
　　　　　　崩撃ヒット（1/6満ち）
　　　　　　打ち上げ攻撃後、追撃ジャンプのときに空中必殺技がヒット（1/6満ち）
　　　　　　必殺技のカウンターヒット（1/6満ち）
　　　　　　超必殺技ヒット（1/6満ち）
　　　　　　一部超必殺技のカウンターヒット（2/6満ち）
　　　　◇欠ける
　　　　　　ラウンドをまたぐ（1/6欠け）
　　　　　　真必殺技を使う（1/6欠け）
　　　　　　真必殺技をあてる（6/6欠け）

　　※月は一回のコンボで満ちる数に制限があります。（初期状態で3/6）
　　※また、一回のコンボ中に同じ技で二回月が満ちることはありません。

◆特殊攻撃技解説
◇立ち強パンチ
　　左右のフック。
　　　※相手にあてるかガードされたとき、もう一度Y入力で追撃を出すことができます。

◇しゃがみ強キック
　　打ち上げ攻撃です。
　　　※あてると相手は高く吹き飛びます。
　　　※ヒット時に7or8or9入力で、左右に空中制動のできる追撃ジャンプに移行ですます。
　　　※追撃ジャンプ中に必殺技「ハンガーミサイル」をあてることで、月齢ゲージを1/6満ちさせることができます。

◇崩撃
　　前方に突進しながら両手での叩きつぶし。
　　くらった相手はその場にくずれ落ちます。
　　　※6＋Yで出せる強制ダウン攻撃の、Yを押し続けることで出すことができます。
　　　※ガード不可能打撃技。
　　　※Yボタンの溜めがおわると発光し、突進中には相手に攻撃にひるまないアーマー状態になります。
　　　※地上の相手にあてるとくずれ落ち状態になり追撃が可能、空中の相手は普通に吹っ飛んでダウンします。
　　　※あてれば月齢ゲージを1/6満ちさせることができます。
　　　※Yボタンを溜まりきるまえに離すと、通常の強制ダウン攻撃が出ます。
　　　※Yボタンの溜め中はダッシュ・バックステップでキャンセルすることができます。

◇中段攻撃
　　スパナを相手の頭に振り下ろします。
　　　※しゃがみガード不可能。

◇投げ
　　バケツに突っ込んで爆破。
　　　※攻撃判定が発生するまでに相手の通常投げ攻撃を受けると、「投げぬけ」状態になります。
　　　※こちらの投げがあたったとき、投げられた側が6or4＋"recovery"コマンドの入力で「投げぬけられ」状態になります。
　　　※どちらの場合も一定距離が開いたのち、両者同時に立ち状態に戻ります。
　　　※くらいアニメに7697番を使用しているので、そこに別のアニメを登録してあるキャラクターにあてると表示がおかしくなります。
　　　※（そのアニメ番号のあいだは無敵のため、ゲーム自体は問題なく進むと思います）

◇ガードキャンセル攻撃（ゲージ1000消費）
　　踏み込んでの体当たりで相手を吹き飛ばします。
　　　※ガード時にのみ出すことができます。
　　　※Powerゲージを1000消費。
　　　※この技で相手をKOすることはできません。
　　　※発生が遅いため、安易に使うとガードされて反撃を受けるかもしれません。

◆必殺技
◇グレネード
　　手榴弾。
　　　※放物線を描いて飛び、相手にあたるか一定距離で爆発します。
　　　※弱は低く、強は遠くに投げます。
　　　※いちどに一個のみ使用可能。
　　　※敵にあたると爆発するのに、地面に落ちてもバウンドするだけの高性能起爆装置。

◇スタンガンネイル
　　しびれるシェイクハンド。
　　　※前方に電撃で攻撃します。
　　　※弱なら正面に、強なら斜め上に出します。
　　　※判定は長めですが、敵にあたるかガードされるとすぐにやめます。
　　　※確実にダウンさせることができるので、連続技のお供に。
　　　※くらいアニメに7696番を使用しているので、そこに別のアニメを登録してあるキャラクターにあてると表示がおかしくなります。
　　　※（そのアニメ番号のあいだは無敵のため、ゲーム自体は問題なく進むと思います）

◇プリティドール
　　かわいいお人形。
　　ほら！持ってって持ってって持ってって！
　　　※荷物を背負ったお人形を設置します。
　　　※お人形は一定時間相手にむかって歩いたあと停止、荷物の酸爆弾が炸裂します。
　　　※強で出すと歩く距離がのびます。
　　　※隙は大きいですが、出してしまえば爆発は確実にするので、相手のダウン中などには積極的に。

◇レーザーソバット
　　もう短足とは言わせない。
　　　※足からレーザーブレードを出し、相手をなぎはらいます。
　　　※弱で2回、強で3回攻撃します。
　　　※前進するためリーチがありますが、ガードされてもあたっても不利フレームがあります。
　　　※強で出すとさらに不利が大きく、画面端だとあたっても反撃を受けかねません。

◇ハンガーミサイル（空中専用）
　　片手にミサイル。
　　片手にアサルトライフル……は持っていない。
　　　※ミサイルにつかまって空中を飛びます。
　　　※一定距離を進むか、AorBorXorYボタンを押すことで離脱して飛び降ります。
　　　※飛び降りるさい、ミサイルは飛び道具として前方に進み続けます。
　　　※降下中に別の行動可能。
　　　※強で出すと速く飛びますが、飛び降りたときに行動可能になるまでの時間が少し長くなります。
　　　※画面内にミサイルがあると出せません。

◆超必殺技
◇ハンターバニー（ゲージ1000消費）
　　クールに狩ろう。
　　　※屈強なハンターを支援に呼んでの一斉射撃。
　　　※ハンターは高い位置にレーザーを、自分は正面にハンドガンを射撃します。
　　　※Powerゲージを1000消費。
　　　※暗転中のみ無敵。
　　　※ハンターの攻撃があたると月齢ゲージを1/6満ちさせることができます。
　　　※隙が大きいのでコンボ用と割り切るのがいいかもしれません。

◇グレートボム（ゲージ1000消費）
　　大型爆弾。
　　面倒な相手にはこれが一番。
　　　※ジャンプしながら足元に爆弾を叩きつけ、爆風で攻撃します。
　　　※Powerゲージを1000消費。
　　　※投擲後上昇中まで無敵。
　　　※爆風があたると月齢ゲージを1/6、相手の攻撃にカウンターであてると2/6満ちさせることができます。
　　　※前方への攻撃範囲は短めですが、無敵が長く、ガードされても隙がほとんど無いため切り返しとして優秀です。
　　　※ダウン状態の相手にもあたるため、拾いコンボにも。

◇レーザークローラッシュ（ゲージ1000消費）
　　腕より長い爪だって収納できる。
　　そう、レーザーならね。
　　　※両手からレーザークローを出して、前進しながら連続で斬りつけます。
　　　※Powerゲージを1000消費。
　　　※最初の攻撃判定が出るまで無敵。
　　　※攻撃があたると月齢ゲージを1/6、相手の攻撃にカウンターであてると2/6満ちさせることができます。
　　　※攻撃発生が早く、前進してリーチもあるためコンボに、切り返しにと重宝します。
　　　※ただしガードされると密着状態で隙ができてしまいます。

◇ティーパーティーへの招待状（ゲージ1000消費）
　　（ただし客としてもてなすとは書いていない）
　　　※相手をカギ爪マシンで捕まえ、紅茶を楽しみつつ鑑賞します。
　　　※Powerゲージを1000消費。
　　　※無敵なし。
　　　※攻撃があたると月齢ゲージを1/6満ちさせることができます。
　　　※ガード不可能、地上の相手専用の投げ判定技。
　　　※くらい・ガード状態（Movetype=H）の相手にはあたりません。
　　　※カギ爪は敵をサーチして、相手の真下から出現します。
　　　※奇襲やガードくずし、遠距離での飛び道具狩りなどに使える遠距離投げ技です。
　　　※あたらないと大きな隙をさらすことになります。

◇ジャッジメントバインド（ゲージ1000消費）
　　天国に昇らせるか地獄に落とすか。
　　無罪？ありません。
　　　※相手を捕まえて磔にし、爆破します。
　　　※Powerゲージを1000消費。
　　　※攻撃判定発生まで無敵。
　　　※攻撃があたると月齢ゲージを1/6満ちさせることができます。
　　　※地上の相手専用の投げ技。
　　　※威力としては、通常の投げから超必殺技で追撃したときと大きくは変わりません。
　　　※しかし通常の投げに比べると、無敵があり、リーチが長く、投げぬけされないという利点があります。
　　　※くらいアニメに7697番を使用しているので、そこに別のアニメを登録してあるキャラクターにあてると表示がおかしくなります。
　　　※（そのアニメ番号のあいだは無敵のため、ゲーム自体は問題なく進むと思います）

◆真必殺技
◇エクストリームランアウェイ（満月時専用）（ゲージ1000必要）（全ゲージ消費）
　　ばいばいばーい。
　　　※突進したあと相手を上空に打ちあげ、バギーで跳ね飛ばします。
　　　※月齢ゲージが満月状態限定。
　　　※Powerゲージが1000以上必要で、出せば全ゲージを消費します。
　　　※暗転中のみ無敵。
　　　※一撃必殺技です。
　　　※無敵は攻撃発生前に切れますが、判定発生は早めなのでコンボに組み込むことができます。

◆その他

◇キャンセルルート
　　　※ヒット・ガード時に技の戻りをキャンセルして攻撃可能。
　　　※キャンセルルートは以下のとおりです（途中を飛ばすこともできます）。
　　　※地上通常
　　　　（立ち弱P・しゃがみ弱P・しゃがみ弱K）→（立ち弱K）→（近立ち強P・立ち強K）→（強制ダウン攻撃・必殺技・超必殺技・真必殺技）
　　　　　　　　　　　　　　　　　　　　　　　　　　↓
　　　　　　　　　　　　　　　　　　　　　　　　（しゃがみ強P・しゃがみ強K））
　　　※空中攻撃
　　　　（弱P）→（弱K）→（強P・強K・ボディプレス）→（必殺技）

◇カラーについて
　　12色が用意されています。
　　選択時はABCXYZボタンと、S＋ABCXYZ

◇本体設定項目
　　Tiny_Rabbit.cnsファイルの最下部に、本体の設定項目があります。
　　主に月齢ゲージ関連の設定です。
　　　※「月齢ゲージ表示位置」
　　　※「登場時月齢」
　　　※「一回のコンボで月が満ちる上限」
　　　※の設定ができます。
　　　※真必殺技を使えないようにすることもできます。

　　勝利ポーズや一部技中に出している、画面固定用のヘルパーを出さなくすることができます。
　　　※mugen1.1でステージの拡大縮小機能を使いたいときなどに。

　　Tiny_Rabbit.defのMugenVersionを1.0以降にして使う場合も、ここの硬直増加設定を変えてください。

◇AI
　　Tiny_Rabbit_AI.cnsファイルの最初に、常時AIスイッチとAIレベルの設定項目があります。
　　　※デフォルト状態は常時AIスイッチ value = 0でAIオフです。

　　　※AIスイッチ value = 1はAIのコンボテスト用です。
　　　※プレイヤーのキー入力で動きますが、技が当たったときに自動でコンボ動作をとります。

　　　※立ち回り等の動きを含めたAIはスイッチ=2になります。
　　　※コマンド入力とヘルパー式のAI起動を併用していますが、この常時AI設定項目でvalue = 2にしていただければ間違いなく起動します。
　　　※AI戦動画などで使用される場合にはぜひ活用ください。

　　　※AIレベルの変更ができます。
　　　※くわしくはTiny_Rabbit_AI.cnsファイルをご覧ください。
