○基本仕様

４ボタン
 x : 弱パンチ攻撃
 y : 強パンチ攻撃
 a : 弱キック攻撃 
 b : 強キック攻撃

 66 : 前ダッシュ
 44 : 後ダッシュ

○システム

※基本的には、歴代のKOFのシステムを大体取り入れられるようにしています。

※カウンターモード？ドライブゲージ？スキルゲージ？どこでもキャンセル？なにそれ怖い・・・

・ジャンプ
上要素(7・8・9のどれか)を押すと通常ジャンプ。
短く上要素を押してすぐ話せば小ジャンプ。
下を入力した後上要素を押すと大ジャンプ。
下を入力した後に上要素を押し素早く離すと中ジャンプ。

・緊急回避
X、Aボタン同時押し。投げ以外に無敵になり移動する。
ガード硬直時に1ゲージ消費で使用可能。ガーキャンで使用した場合は投げに対しても無敵。

・ふっとばし攻撃
Y、Bボタン同時押し。ガード硬直時に1ゲージ消費で使用可能。

・パワーMAX
94のような自動発動ではなく、98のようにパワーゲージ1本以上のときに
X、Y、Aボタン同時推しで任意発動。
発動中攻撃力1.5倍、披ダメージ0.8倍、MAX超必殺技が使用可(後述)。
また、2ゲージ消費し、ガード硬直や通常技をキャンセルして発動することも出来る(クイックMAX発動)。

・パワー溜め
A、B、Yを押しっぱなしでパワーゲージをチャージ。

・挑発
Sボタンで発動。相手のゲージを減らす効果はなし。

・その他
攻撃避けはなし、カウンター攻撃もなし、一部どこでも判定付きの技あり。

○特殊技
・ 3 + Y : 連続パンチ。名称不明。
・ 3 + A : スライディング。名称不明。
・(空中で)2 + A : 急降下技。名称不明。相手をめくれる。

・ 6 + Y : 通常投げ。
・ (空中で)6 + Y : 空中投げ。



○必殺技解説

※以下、(★)マークはお梅さんが使用可能時のみ。

・4ため6 + P : 甲式・岩砕歯
弧を描く飛び道具。使いづらい。

・4ため6 + K : 甲式・威嚇顔
画面はしまで届く前に消える飛び道具。牽制に。

・2ため8 + K : 甲式・天舞脚
飛び上がって蹴り。出始め無敵あり。

・41236 + P : 甲式・流星乱舞弾
相手を投げて連続エネルギー弾を食らわせる。

・236 + P : 岩砕歯(★)
お梅が後ろから入れ歯を投げる。

・41236 + K : 流星乱舞弾(★)
お梅が後ろから連続エネルギー弾。

・236 + K : 天舞脚(★)
上からお梅が降ってくる。




○超必殺技解説

・2141236 + P : 絶鬼掌
1ゲージ使用。出が遅いガード不能の飛び道具で当たれば相手をロックする。
原作では死に技だったので一部の通常技から繋がるぐらい発生を早めた。

・236236 + P : 豪炎球
1ゲージ使用。小技から繋がるほど発生が早い飛び道具。

・632146 + P : 桃恋火
1ゲージ使用。若返って飛び上がり、投げキッスで追撃。性質としてはコマンド投げ。
原作のコマンドは236236Pだけど投げ技としては強すぎるのでKOFっぽいコマンドに変更。

・214214 + AorBorXorY : 御顔柱(★)
1ゲージ使用。押したボタンで柱の位置が変わる。



○MAX超必殺技解説
　※MAX発動中なら1ゲージで使用可能、それ以外なら2ゲージ使用。

・2141236 + PP : 森羅鏡
自分の分身を飛ばす飛び道具。豪血寺外伝っぽい性能。削りがものすごい以外に使い道がない。

・236236 + PP : 真・豪炎球
豪炎球を3つ連発する。ドリームキャンセル対応技。

・632146 + PP : 憎恋火
若返って飛び上がり、投げキッスで追撃。性質としてはコマンド投げ。

・214214 + PP : 真・御顔柱(★)
相手をサーチして足元からいくつもの柱を出す。


○MAX2超必殺技・NEOMAX超必殺技解説

・6321463214 + PP : 色恋無双(★)
MAX2。体力1/3以下、3ゲージ使用(MAX発動中なら1ゲージ)で発動。
性能としてはコマンド投げ。若返り、相手を投げつけたあとお梅と二人で乱舞。
名前は先祖供養のお梅の若返り時の一発奥義から。

・1346 + B+Y : 絶吻
NEOMAX。4ゲージ使用(MAX発動中なら2ゲージ)で発動。
最初に飛び道具判定の分身を出して、当たれば演出に移行。
先祖供養のお梅の技だけど、まぁお種さんも使えるってことで。

○Config

・スーパーキャンセル可能スイッチ
必殺技をキャンセルし超必殺技を出すことが可能に。

・ドリームキャンセル可能スイッチ
超必殺技・MAX超必殺技をキャンセルし真・豪炎球を出すことが可能に。
(MAX2超必殺技、NEOMAX超必殺技、真・豪炎球からはキャンセル不可能)

・MAXキャンセル可能スイッチ
必殺技・超必殺技・MAX超必殺技をキャンセルしNEOMAX超必殺技を出すことが可能に。
(MAX2超必殺技、NEOMAX超必殺技からはキャンセル不可能)

・EXモード超必殺技可能スイッチ
体力1/8以下で、1ゲージ超必殺技に限り体力消費なしで使用可能に
