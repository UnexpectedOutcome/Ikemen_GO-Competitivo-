--------------------------------------------- EMW's readme -----------------------------------------------
----------------------------------------------------------------------------------------------------------
Typed on 2/1/08
I downloaded this Link a long while ago (6 months???) anyway, I enjoyed the sprites he had, and he looked
like a potential character. During the time I first began to continue the creation of this character I had
just downloaded LOZ: Ocarina of Time from the Wii's virtual Console in the shop. Playing the game brought 
back many memories! I always loved the game. After playing and completing the game in about a week, I went
back to my dusty computer which hadn't been used much since I got the Wii. I wanted to make another normal
sized character (Unlike the Pesky Plummers, and Paper Mario) and I wanted to make a Nintendo character again. 
So I opened him in FF and saw many nicely edited sprites! I did notice many problems such as alignment, 
sparks, and clsns! I wanted to See this Link finished.

--------------------------------------------- Movelist ---------------------------------------------------
----------------------------------------------------------------------------------------------------------

------------
Basics:
------------
Light Punch = X ;Link does a punch
Medium Punch = Y ;Link Swings the Master Sword
Feirce Punch = Z ;Link Swings the Master Sword
Low Kick = A ;Link Knees the Opponent
Medium Kick = B ;Link does a kick
Feirce Kick = C ;Link Shifts his Sword forward in a stab-like manner.
Launcher = Crouching HP
Super Jump = Down, Up
Guard Push = x+y (While guarding)
Recovery Roll = left or right (before you get up)

Selecting Dark Link = Hold start and press any attack button while selecting Link.
------------
Specials:
------------

Boomerang Throw = Down, Forward, Punch Button ;Link throws the boomerang.
X = horizontai
Y = Diagnal Upwards 
Z = Diagnal Upwards (Faster and higher)


Spin Attack = Down, Back, Punch Button ;Link spins around with his sword out.
This move can be preformed in the air.


Hero's Bow = Down, Forward, Kick Button ;Lanches a arrow. It's fast.
A and B = The arrow fall to the ground a little.
C = The arrow keeps at a constant X velocity. Doesn't fall.


Hookshot = Down, Back, Kick Button ;Pulls P2 to you and stuns them for a few seconds.
A = Short but long stun time
B = Medium distance and stun time
C = Long distance and short stun time


Bomb = x+a ;Link tosses a bomb.
If the bomb hits P2 while in the air, its explodes on impact.
If the bomb hits the floor, its will stay there for a few seconds when it starts to flash red, its about
to explode.


Sword Dive (Dark Link Only) = Down, Forward, Kick button (In air) ;Dark Link Dives at P2 with his sword.
Button determines speed. 


Downward Thrust = Down + Kick button (in air)
B does 2 hits with the bounce.

Rapid Slash = Tap any punch button repeatedly.


Megaton Hammer = Forward, Down, Foward, Punch button ;Link pulls out the Megaton Hammer and slams on the ground.


Warp Forward (Dark Link Only) = F,D,F, Kick Button ;Dark Link warps forward. Button determines distance

Warp Back (Dark Link Only) = B,D,B, Kick Button ;Dark Link Warps Backwards. Button determines distance

-------------
LVL 1 Hypers:
-------------
Light Arrow: (Link Only) Down, Forward, Two Kicks ;An enhanced version of the Hero's Bow. Faster, Stronger.


Super Spin Attack: Down, Back, Two Punches ;An enhanced version of the Spin Attack, very similar to a Super Hurricane Kick.
-------------
LVL 2 Hypers:
-------------
Hidden Skills = Down, Forward, High Punch + High Kick ; Link preforms some of his Hidden skills from
Twilight Princess. Ends with a finishing blow.

Deku Nut Toss = Forward, Down, Forward, 2 Punches ; Link tosses a Deku Nut, if it hits P2 is blinded for
a few seconds. Link slashes away in a SGS-like manner.
-------------
LVL 3 Hypers:
-------------

Triforce Slash (Link Only) = Down, Forward, Two Punches ;Link's Final Smash from Super Smash Bros Brawl. warps to P2 on sucess.

Darkness Slash (Dark Link Only) = Down, Forward, Two Punches ;Dark link thrusts his sword forward in a stab like motion. If sucessful, the screen fades out and Dark Link slashes away at p2 with white flashes showing how he attacks them.
