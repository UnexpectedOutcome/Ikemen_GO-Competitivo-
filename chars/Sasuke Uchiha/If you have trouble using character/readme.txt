This hacked build supposedly increases the memory limit (RAM) from 2GB to 4GB on x64 platforms, allowing the use of heavier memory content.

This unofficial build may introduce stability and compatibility issues so it's NOT recommended and NOT meant for general use either. This is NOT an optimized nor a faster build. Use it at your own risk, and only as a last resort if you experience difficulties related to memory heavy content, that even the OpenGL video mode couldn't fix.




At Mugen 1.1 Beta Opengl, I have checked that using this would solve the Error problem.
