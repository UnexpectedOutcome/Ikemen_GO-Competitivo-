★ボタン
	a	パンチ
	b	斬り攻撃
	c	強斬り攻撃
	x	キック
	y	ダッシュサポートボタン
	z	一部技に使用
	s	挑発

------------------------------------------------------------------------------
★特殊行動
	近距離で6+c	投げ
	近距離で4+c

	66			ダッシュ
	6+y			普通のダッシュです

	44			バックステップ
	4+y			発生から無敵時間があり、終了とともに無敵が切れます

	素早く28	ハイジャンプ
	素早く29	小ジャンプもあり
	素早く27	入力補助として、
				yを押しながらジャンプすると大ジャンプに、
				zを押しながらジャンプすると中ジャンプになります
				（両方押している場合、中ジャンプが優先）

	6+a			裏拳
				手前の腕の手甲を打ち付ける裏拳
				飛び道具属性の攻撃を打ち消す効果あり
				飛び道具を打ち消した場合それなりにゲージ増加
				通常攻撃からキャンセルして出せます
				飛び道具を打ち消した瞬間を必殺技以上でキャンセルできます

	3+x			スライディング
				ダウンを奪います

	壁際でレバー
	反対方向	三角飛び
				壁を蹴ってジャンプ
				yまたはzを押しながら三角飛びすると飛距離が伸びます
				小・中ジャンプ時は使えません

------------------------------------------------------------------------------
★特殊テクニック
	チェーンコンボ
	恭介は地上攻撃のみ、パンチ→キック→武器攻撃→強武器攻撃の順でキャンセルできます
	空中チェーンはありません
	（ジャンプパンチは連打可能ですが回数制限あり）

------------------------------------------------------------------------------
★必殺技
	236 + b		朧薙
	236 + c		前方にダッシュしながら斬りつけます
				b版は表、c版は裏に回って斬ります
				（c版はガード方向が逆になります）

	623 + b		月断
	623 + c		対空攻撃
				b版はやや真上、c版は斜め前上に攻撃
				単発で出した場合は空中ガード不可、キャンセルで出した場合は空中ガード可能

	236 + x		霞移
				高速で相手の手前上空に移動する技
				移動後に行動可能

	空中で
	214 + b		雲斬
				前方に飛び掛かり相手の頭を掴む対地コマンド投げ
				成立すると背後に回って上から斬る
				コンボ組み込み不可、発動位置が低すぎると掴めない

------------------------------------------------------------------------------
★超必殺技
	236 + a + b		虎牙（1ゲージ）
	236 + y			前方突進技
					b版朧薙の強化版のような性能で、ヒットすると蹴り・首折り・斬撃を繰り出す

	空中で
	63214 + a+ b	鷲爪
	63214 + y		暗転時確定の空中コマンド投げ
					画面端まで追いやってから追撃する
					コンボ組み込み不可

	236 + b + c		黄泉路（2ゲージ）
	236 + z			飛び上がり斜め上方向へ攻撃する
					単発で出した場合は空中ガード不可、キャンセルで出した場合は空中ガード可能
					斬り抜けた先に着地後、振り返り再度斬り抜ける
