  括弧內數字代表……(組,索引)編號。
  可以利用Fighter Factory Studio看到這個圖像數值。
  The numbers in parentheses represent...(Group,Index) number.
  You can use Fighter Factory Studio to see this image value.

  Fighter Factory Studio:
  http://fighterfactory.virtualltek.com/download

  所有血條皆支援localcoord = 1280,720.
  這個數值並不是血條的localcoord數值，而是畫面包的localcoord數值。
  All lifebars support localcoord = 1280,720.
  This value is not the localcoord value of the Lifebar, 
  but the localcoord value of the Screenpack.

  由於人物localcoord為1920,1080數值，
  所以圖片比例大小(跟1280,720比較)多加了1.5倍。
  Since the character localcoord is 1920,1080 values,
  So the image ratio size (compared to 1280,720) is increased by 1.5 times.
