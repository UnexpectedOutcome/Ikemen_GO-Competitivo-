 ● 連鎖普通技 Chain Normal Moves ●

;━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
○連鎖亂擊                             [(MoveContact), yyyyy]
  Chain Barrage

  如果接觸到對手連續輸入Y鍵，因為代碼設計關係，會自動形成一組連鎖亂擊。
  If contact enemy continuously enters the Y key, 
  because of the code design relationship, a set of 
  Chain Barrage will be automatically formed.

  主要有五連段，倒數第二段為百花槍。
  There are mainly five combo, the penultimate combo is Hyakka Spear.

  在連鎖亂擊倒數第二段(百花槍)時能量1000點以上
  接觸到對手，會自動連段使用 → 真空波動槍。
  In Chain Barrage penultimate combo (Hyakka Spear), 
  the power exceeds 1000 value and contact 
  the enemy, it will automatically combo used → Vacuum Wave Spear.

  Crouch Chain Barrage

  接觸到對手輸入Y鍵，會形成一組連鎖亂擊。
  Contact enemy and enter Y key to form a set of Chain Barrage.

  Contact enemy and enter Y key to form a set of Chain Barrage.
