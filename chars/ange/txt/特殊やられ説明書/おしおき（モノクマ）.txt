・モノクマ（道端さん製作）　～おしおき

“monokuma.cns”内で"任意お仕置き"と検索して、まず

;[State 4010,任意お仕置き]
;type = ChangeState
;triggerall = time = 485
;trigger1 = enemynear,name="MONOKUMA"このトリガーは消してください
;value = 15500

↑
このような所がありますので、このステート記述を

[State 4010,任意お仕置き]
type = ChangeState
triggerall = time = 485
trigger1 = enemynear,name="USHIROMIYA ANGE"
value = 15500

↑
このように書き換えます。

次に、さらに"任意お仕置き"で検索して

;[State 4100,任意お仕置き]
;type = SelfState
;trigger1 = time = 485
;trigger1 = SelfAnimExist(14500)
;value = 14500

↑
このような所がありますので、このステート記述を

[State 4100,任意お仕置き]
type = SelfState
trigger1 = time = 485
trigger1 = SelfAnimExist(14500)
value = 14500

↑
このように書き換えます。

以上、計2ヶ所を書き換えれば完了です。
記述に問題がなければ、縁寿がモノクマのおしおきを喰らった際のおしおき演出が縁寿独自のものが表示されるはずです。
