Description
-----------
!!!
A Magician appears!

Well, for my latest project, I tried to
convert the famed RPG boss from Kirby Super
Star (Ultra). There *was* another version
before this one, but it's both in japanese
and based on the SNES version of the boss,
so I feel I still did something unique.

The character isn't controllable by a player, so
there's not much point in putting a movelist.

x, y, z = Fight Slime, Puppet and Magician
a, b = Fight Magician, Evil Knight and Great Dragon
c = Fight all of them

Hold start to change the character's palette
