--------------------------------------------------------------------------------
初めの駄文
--------------------------------------------------------------------------------
BIGBANG BEATから漢を目指す男!!こと陣内兵太です
エンハウンスが全てのキャラです
(まあ、無くても十分いけますが………)

完成度は限りなく低くなると思います
また、現在はヒットエフェクトが一部異なっております

Mugenの仕様上、完全に変身する事はできません
そのため、相手の特定の攻撃を受けた時にカラーが戻ってしまう事があります
(アンケートの結果、画像が戻っても無視という事になりました)
それ(相手がステート奪う技)以外の状態で、画像が戻ってしまった場合、できる限り、その時の状況の報告をお願いします

ちなみに、カラー募集してます
もし作ってやるよっていう方いたら連絡くださいな

なお、9Pカラー以降で選択した場合、スーパー兵太が使用できます
今後の更新で、常時スーパー兵太も追加したいなぁと思ってます

ボタン配置
--------------------------------------------------------------------------------
A = 弱攻撃
B = 中攻撃
C = 強攻撃
Z = Bアクションボタン
X = チャージボタン
Y = エンハンスボタン
START = 現在未使用

なお、CAPCOM配列にしたい方(ようはCAPCOMやSNKキャラと戦いたい方)は
CMDの一番上にある[Remap]の部分の;を全て外してください
ちなみに、外すと

X = 弱攻撃
Y = 中攻撃
B = 強攻撃
A = Bアクションボタン
Z = チャージボタン
C = エンハンスボタン
START = 現在未使用

というボタン配置になります

なお、人によっては中攻撃を下に持って行きたい方もいるでしょうから
そういう場合はCMDの二番目にある[Remap]の部分の;を全て外してください
ちなみに、外すと

X = 弱攻撃
A = 中攻撃
B = 強攻撃
Y = Bアクションボタン
Z = チャージボタン
C = エンハンスボタン
START = 現在未使用

というボタン配置になります

その他のボタン配置にしたい方は３番目を自分で弄ってください

--------------------------------------------------------------------------------
AIについて
--------------------------------------------------------------------------------
AIはCnsフォルダにあるsystem_modeを弄れば変える事ができます
また、変身の頻度が変わる戦闘スタイルを設定する事ができます
(デフォルトではAIはNo AIに、スタイルは使用しないに設定されています)
なお、常時変身選択した場合、常時の制限が外れる行動をしてくる事があります

また、最初からAIが入った状態で、戦闘を開始したい場合は
Cnsフォルダ内のstcommonを開いて、一番下の方にある
[State 最初からAIあり]の下のNull;を外してください

--------------------------------------------------------------------------------
使用可能システム
--------------------------------------------------------------------------------
投げ　　　　　　　　　  投げは投げ
                        地上で横を押しながら強攻撃で出せる
                        若干、発生が遅いが、見てからの回避は厳しい
                        失敗しても、横入力強攻撃が出るので安心

フィジカルゲージ        略してＰゲージ
　　　　　　　　　　　　強攻撃や必殺技、投げなどを使用すると減っていき、ゲージが無くなると技が出せなくなる
                        なお、ライフが減っているとその分、Ｐゲージの最大値が増える
                        ちなみに、時間の他、チャージ、アドバンスドチャージ、エクステンドチャージなどでも回復する

Ｂダッシュ              攻撃の隙をキャンセルして行うダッシュ
　　　　　　　　　　　　地上ではＮor横or下＋Ｂ、空中はＮor横or上or下＋Ｂで出せる
                        １ゲージ消費。コンボのお供にどうぞ
                        ちょっと昔に流行った曲名じゃないよ

Ｂカウンター            ガード中に反撃できる技
　　　　　　　　　　　　地上ガード時に横＋Ｂで１ゲージ消費で出せる
                        ただし、相手に読まれるとＢダッシュに化けるので注意

Ｂエスケープ            喰らっている最中に脱出できる技
　　　　　　　　　　　　横＋Ｂで４ゲージ消費で出せる
                        ゲージ消費量が多いので使いどころは要注意

チャージ                Ｐゲージを回復させる手段の一つ
                        押しっぱなしにするコトで持続し、一定時間経過後から徐々にＰゲージが回復し始める
                        そのため、こまめにやってもあまり意味がない
　　　　　　　　　　　　相手をダウンさせた後などに使うのがベスト
                        スーパー時はいきなり回復し始める

アドバンスドチャージ　　Ｐゲージを回復させる手段
                        下２回とチャージボタンで使用可能
                        １ゲージを消費するが、いきなり多くのゲージを回復できる他
　　　　　　　　　　　　チャージと違い、押しっぱなしにしていた場合、即ゲージを回復し始める
　　　　　　　　　　　　スーパー兵太は一度の使用でMAXまで回復できる

エクステンドチャージ    Ｐゲージを回復させる手段
                        チャージもしくはアドバンスドチャージ中にチャージボタン押しっぱなしで十字キーを一回転させる
                        チャージの２倍のＰゲージを回復する他、攻撃力も上がっていく
                        ただし、その代償としてライフがどんどん減っていく
                        
エンハンス              三回だけ使用できるキャラ特有の動作
　　　　　　　　　　　　兵太は４回使用した場合に変身可能
                        なお、一回使用する事に各種技が強化されていく
　　　　　　　　　　　　スーパー兵太はアレンジ要素としてジヤストディフェンスが使用可能に
                        
振り向き攻撃            相手を飛び越した状態(相手に背を向けている状態)で２段ジャンプ前なら
                        上押しながら攻撃ボタンで相手の方へ落下しつつ攻撃する
                        タイミングは若干シビアだが、なかなかに強いので慣れると良いかも

--------------------------------------------------------------------------------
アレンジ要素説明
--------------------------------------------------------------------------------
通常兵太時

前弱攻撃の追加
根性走りを一度だけアーマー付加から一度だけ無敵付加に変更
エンハンスを使用する度に、一部技の強化されるように
１度使用  通常技を前弱攻撃、必殺技を漢対空、弱漢対空を必殺技でキャンセルできるように
２度使用  漢のナックルとナックルキャンセルダッシュのＰゲージ消費量減少
３度使用  ど根性走りの無敵付加が２回まで無敵になるように

スーパー兵太時

前強攻撃の追加
エンハンスの使用回数分、ジャストディフェンスが可能に
各種攻撃、一年ナックルの決めポーズをエンハンスでキャンセル可能に
空中漢対空時、攻撃判定発生前の重力を無しに
超必殺技版陣内流天空脚の追加
10年ナックルの演出強化(？)

--------------------------------------------------------------------------------
スーパー兵太制限説明
--------------------------------------------------------------------------------
9Pカラー以降でのスーパー兵太の場合、変身でのスーパー兵太よりも能力が大幅に低下します

具体的に言うと

前強攻撃使用不可能
チャージの回復速度減少
アドヴンスドチャージの回復量減少
エンハンスの使用しても、ジャストディフェンス使用不可能
各種動作をエンハウンスでキャンセル不可能
超必殺技版陣内流天空脚の削除

となります

最初から変身状態でのスーパー兵太で闘いたいという場合は
system_modeのスーパー兵太制限を弄ってください
デフォルトでは通常通りになっています
