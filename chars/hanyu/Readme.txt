■覚醒について
　一度負けると覚醒し、以下の仕様になります。
　・何もしなくてもPowerが徐々に増加
　・攻撃力が1.1倍
　・「ハリケーンミキサー」が「柳桜一文字斬り」に変化
　・「ヒナミ・ザ・ワールド　」が「柳桜咆哮」に変化
　・特殊攻撃が全て「鬼狩柳桜」による剣撃へ変化

　覚醒しないようにするには「hanyu_0.cns」ファイルをメモ帳などテキストエディタで開き、
　「覚醒の有無の定義」と記載されている箇所を検索（Statedef 190）。
　　valueの値をいずれかに変更する(デフォルトでは「0」に設定)。
	 0 → 覚醒あり(デフォルト）
	-1 → 覚醒なし

■AIについて（㍻㌢さんのAIを参考にして作成しています・・・が、色々混じってます）
　AI強さについて、デフォルトは"7"です。1～10まであり、10が最強です。

■その他
・Startを押しながらキャラ決定（ボタンはどれでも可）で、初戦から覚醒状態になります。
　※なお、プレイには支障ありませんが専用イントロがうまく動作しなくなります。
・ヒートアップが他のキャラに比べ時間が長い反面、Life回復速度を遅く設定しています。
　（反撃のヒートアップを頻繁に使えなくするため）
・ヒナミ・ザ・ワールドの溜め中、射撃攻撃は無効にしてます。避けるには、タイミングよく
　回避行動をとるか、直接殴って止めてください。
・「オヤシロバリア」中、射撃攻撃は無効にしてます。
　（反射出来ない処理をしてる射撃攻撃に対する処置）
・「オヤシロバリア」で、鷹野の「山狗総攻撃」を打ち消すことができます。
　（偶然そのような現象になったのですが、そのままにしてます）
