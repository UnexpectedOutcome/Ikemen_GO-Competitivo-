--------AIに技を追加するテンプレート--------

;カチドキ砲
[State -3, Super Arts]
type = ChangeState
value = 3500 　;ここは飛ばしたいステートのNoをいれてください
triggerall = RoundState = 2　　　　　;死体殴りやフライング防止
TriggerAll = Var(59) = 1             ;AIスイッチがONの時
TriggerAll = Var(58) >= 3            ;AIレベルが3以上の時
triggerall = power >= 2000           ;ゲージが2以上の時
triggerall = var(40) = 1             ;ジンバー発動後
trigger1 = statetype = S             ;立ち状態の時のみ使用可
trigger1 = ctrl                      ;コントロールが１の時
Trigger1 = P2BodyDist X >= 120       ;相手との距離がそれなりに離れてる時
Trigger1 = Random <= 300             ;ランダム


上記のテンプレートで大体の技は入れられます。
AIも基本的には条件が揃ったら、ChangeStateを使ってそのステートに飛ばす
だけなので、条件だけ考えればさほど手間のかかる事ではないです。

下記の例は技を繋げて出す場合

[State -3, Super Arts]
type = ChangeState
value = 3300
triggerall = RoundState = 2
TriggerAll = Var(59) = 1
triggerall = power >= 1000
TriggerAll = P2BodyDist X >= 60
TriggerAll = StateType != A
Trigger1 = StateNo = 230
Trigger1 = MoveHit
Trigger1 = Random <= 600


相手との距離が60以下でゲージが1本以上あるときに
ステート230の攻撃がヒットしたときに、6割の確率でステート3300に飛ばす
といった感じです。



☆注意☆

AIもステコンを応用しているだけなので、ルールは一緒です。
上の方にあるステートが優先されます。
なので条件が厳しいものや、優先して出したいものは上に。
条件が揃いやすいものは下にしなければなりません。

つまりゲージ技を下にして、通常技を上にすると
通常技ばかり乱発してゲージ技をなかなか使ってくれなくなります。

Var(36) =  カチドキ使用時間記憶
Var(37) =  カチドキGP時間記憶

Var(41) =  スイカアームズ使用制限記憶
Var(45) =  カチドキモード選択

Var(57) =  AI所持ロックシード設定
