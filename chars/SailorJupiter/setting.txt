==========================japanese=================================
※脱衣KOのON/OFF
AIありならvenus_AI.cmdを、AIなしならvenus.cmdを開けて　（txt形式で）

[State -1, setting];ero;脱衣KO ON(1)/OFF(0)
type = varset
trigger1 = 1
v = 39
value = 1   ←1=ON

のvalue = 1をvalue = 0に変更して、セーフでOK

※アクション顔のON/OFF
AIありならvenus_AI.cmdを、AIなしならvenus.cmdを開けて　（txt形式で）

[State -1, setting];kao;アクション顔画像
type = varset
trigger1 = 1
v = 46
value = 1　　←1=ON

のvalue = 1をvalue = 0に変更して、セーフでOK

※アクション顔の座標（アクション顔がOFFだったら無効）
venus.cnsを開けて、（txt形式で）
[State 915,xy];1Pface_xでサーチ

[State 915,xy];1Pface_x
type = varset
trigger1 = 1
v = 47
value = -3　　　←1P X座標

[State 915,xy];1Pface_y
type = varset
trigger1 = 1
v = 48
value = 18　　　←1P Y座標

そして[State 915,xy];2Pface_xでサーチ

[State 915,xy];2Pface_x
type = varset
trigger1 = 1
v = 47
value = -1　　　←2p X座標

[State 915,xy];2Pface_y
type = varset
trigger1 = 1
v = 48
value = 18　　　←2P Y座標

頑張ってください
