============================================================================
	Bストーン対応方法
============================================================================
＜Bストーンについて＞
・Bストーンとは、Bパワーを放出する結晶で、これが各自の特殊能力の源となっています。
・Bストーンは攻撃がヒットした時に放出され、獲得するとゲージが増加します(大:30,小10)。
・敵味方関係なく獲得可能ですが、未対応の敵が取得した場合は、再度攻撃が当たった時に増加となります。
　対応させる事でこれを即時増加させる事ができます。
・対応はバックアップを取るなどして、各自の責任に於いて行って下さい。

;---------------------------------------------------------------------------
＜対応方法＞
１．Config.txt（1.0使用時はConfig1.0.txt）内にあるBストーン対応の項目で、対応させたいキャラ名を追加して下さい。

 {対応例}
;--------------------------------------------------------------------------
;<<OPTION-A6: Bストーン対応>>
[state a, B Stone]
type = VarSet
var(36) = 10
triggerall = numenemy
trigger1 = enemy,authorname = "Songfu"
trigger2 = enemy,name = "nameA"		;対応させたいキャラ名(def内にあるdisplaynameではない方)
trigger2 = enemy,authorname = "authorA"	;そのキャラの作者名(より確実にしたい場合)
trigger3 = enemy,name = "nameB"
trigger3 = enemy,authorname = "authorB"
...

２．対応したいキャラの [Statedef -2] 以下に下の記述を追加してください。

;---------------------------------------------------------------------------
;Bストーン対応
[State -2]
type = PowerAdd
triggerall = numenemy
triggerall = enemy,authorname = "Songfu"
triggerall = enemy,var(36)/10%10 = 1
triggerall = enemy,var(34)/10000 > 0
trigger1 = !numpartner
trigger2 = numpartner
trigger2 = ID < partner,ID
value = 10*(enemy,var(34)/10000)

[State -2]
type = PowerAdd
triggerall = numenemy = 2
triggerall = enemy(1),authorname = "Songfu"
triggerall = enemy(1),var(36)/10%10 = 1
triggerall = enemy(1),var(34)/10000 > 0
trigger1 = !numpartner
trigger2 = numpartner
trigger2 = ID < partner,ID
value = 10*(enemy(1),var(34)/10000)

============================================================================
	BBBR VSイントロ対応方法
============================================================================
＜概要＞
・BBBRのVS画面をアドオンで再現するのは難しかった為、イントロにしてみました。
・相手が対応していれば特殊イントロが発生します。
・煽り文句は2P側のものが表示されますが、これが用意できない場合1P時のみイントロを発生させる事も可能です。
・スタートボタン（私のキャラ側、双方の場合は1P側）でVSイントロのみ飛ばす事ができます。但しAI操作になっていると効きません。
・元は16:10なのでワイド画面にすると本来の感じで見られます。

;---------------------------------------------------------------------------
＜対応方法＞
１．Airファイルに各画像を登録して下さい。

　28990: カットイン	：縦525程度, 下が軸に接するように配置, 個別では軸から最大約140、対面時には軸から最大250より右が表示される
　28992: ポートレート	：縦480程度、下が軸に接し、基本的に画像の中心が軸になるように配置
　28994: 名前（日本語）	：縦60程度、左下端が軸に接するように配置
　28995: 名前（英語）	：縦30程度、同上
　28996: 煽り文句(上段)	：横最大800、軸が中心になるように配置、2P側の時に表示
　28997: 煽り文句(下段)	：同上

　※全て0.5倍で表示している為、用意できる画像に合わせて、[Statedef 28990] のすぐ下にある倍率設定で適宜調整して下さい。

２．本来のイントロの始まりを遅らせる。

　例）	[StateDef 190] にある

	[State 190, 2] ;Go straight to intro.
	type = ChangeState
	trigger1 = Time = 0 ;←これを"Time > 0"にする
	value = 191 ;各イントロステート

３．対応したいキャラの [Statedef -2] の一番最後に下の記述を追加して下さい。

　※[StateDef -2]の後ろに他の[Statedef]を登録している場合もあるので注意。"Statedef"で検索し、あればそのすぐ上に追加して下さい。
