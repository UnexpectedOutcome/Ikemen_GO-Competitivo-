============================================================================
	Enemy's B Stone
============================================================================
This enables the enemy gets power soon.

1.Input the name and the authorname in "Config.txt" or "Config1.0.txt".

<example>
;<<OPTION-A6: Bストーン対応>>
[state a, B Stone]
type = VarSet
var(36) = 10
triggerall = numenemy
trigger1 = enemy,authorname = "Songfu"
trigger2 = enemy,name = "nameA"		;not displayname
trigger2 = enemy,authorname = "authorA"
trigger3 = enemy,name = "nameB"
trigger3 = enemy,authorname = "authorB"
...

2.Add the following under "[StateDef -2]" of the opponent.

[State -2, B Stone]
type = PowerAdd
triggerall = numenemy
triggerall = enemy,authorname = "Songfu"
triggerall = enemy,var(36)/10%10 = 1
triggerall = enemy,var(34)/10000 > 0
trigger1 = !numpartner
trigger2 = numpartner
trigger2 = ID < partner,ID
value = 10*(enemy,var(34)/10000)

[State -2, B Stone]
type = PowerAdd
triggerall = numenemy = 2
triggerall = enemy(1),authorname = "Songfu"
triggerall = enemy(1),var(36)/10%10 = 1
triggerall = enemy(1),var(34)/10000 > 0
trigger1 = !numpartner
trigger2 = numpartner
trigger2 = ID < partner,ID
value = 10*(enemy(1),var(34)/10000)

============================================================================
	BBBR VS INTRO
============================================================================
  Any character can join BBBR Versus intro when meets my new updated characters.
  You can skip by pushing start on my character side, but cannot in CPU mode.

1. Air

  28990: Cut in			:Height about 525. On the horizontal axis.
  28992: Portrait		:Height about 480. On the horizontal axis and the vertical axis pierces the center of the image.
  28994: Name in Japanese	:Height about 60. The left edge on the origin of the coordinate axes.
  28996: Name in English	:Height about 30. Same as above.
  28997: Word High		:Width max 800. The center of image on the origin of the coordinate axes. 2P side only.
  28997: Word low		:Same as above.

  * Half size is shown in default. You can change this at "Statedef 28990".

2. Delay the intro start of the character.

  ex) at [Statedef 190]

	[State 190, 2] ;Go straight to intro.
	type = ChangeState
	trigger1 = Time = 0 ;change to "Time > 0"
	value = 191

3. Add the following the end of "[StateDef -2]" of the character.
