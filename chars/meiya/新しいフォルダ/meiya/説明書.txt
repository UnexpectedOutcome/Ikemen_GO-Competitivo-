キャラクター名　鳴夜（AIグラップラーVer）
アラド戦記で撮影させてもらったキャラから名前を頂きました

＊注意（敬称略）
ハンゲーム,DNF等
著作権は上記にあります。

操作方法
--------
全て右向きの時の操作です。左向きは移動キーのみ左右逆の操作で行います。

    基本操作
    --------
      鳴夜は和訳カンフーマンを土台として作成させて頂きましたので基本操作は同じです
      Ｘは弱パンチ・Ｙは強パンチ・Ａは弱キック・Ｂは強キックになっています。
      Ｚはシールド&投げその２、Ｃは溜めです

      各ボタンの説明：
      D - 下
      F - 前
      U - 上
      B - 後
      x - Ｘボタン
      y - Ｙボタン
      a - Ａボタン
      b - Ｂボタン
　　　c - Ｃボタン
      s - スタートボタン

      DFは斜め前下、UBは斜め後ろ上など、斜め入力はDFUBを２つ組み合わせる表記になっています。
      空中では、一回だけ空中ジャンプが可能です。
      空中受け身を出した瞬間、キーを左右どちらかに押していたら
      その方向に少し移動しながら受け身を取ります。
      横に倒れている時、ボタンを連打すれば起き上がりが速くなります。


    通常動作
    --------
      U              - ジャンプ
      UF             - 前ジャンプ
      F              - 前進
      DF             - しゃがむ
      D              - しゃがむ
      DB             - しゃがみ＆しゃがみガード
      B              - 後退＆ガード（空中では空中ガード）
      UB             - 後ジャンプ
      F, F           - ダッシュ
      B, B           - バックステップ
      xy             - 空中受け身

    立ち通常攻撃
    ------------
      X              - 弱パンチ
      Y              - 強パンチ
      A              - 弱キック
      B              - 強キック

    しゃがみ通常攻撃
    ----------------
      X              - 通常攻撃（連打すると連続して攻撃）
      Y              - ミューズアッパー（溜めているときはアーマー）
      A              - しゃがみ弱キック
      B              - 足払い

    ジャンプ通常攻撃
    ----------------

      A              - ジャンプキック
      B              - コンドルダイブ（ヒット後のみ上に飛ぶ）

    投げ
    ----
      F + y (密着して) - ロープ
      F + c (密着して) - スープレックス（通常攻撃の最後からキャンセル可能ただしゲージを0.3消費）

    必殺技
    ------
      D, BD, B + a   - 崩拳　弱
      D, BD, B + b   - 崩拳　強

      D, BD, B + x   - 疾風脚　(空中可）

      F, D, DF + x   - ブレイキングエルボー
      F, D, DF + y   - アッパー　(空中可）

      F, D, DF + a   - 金剛崩　弱
      F, D, DF + b   - 金剛崩　強

      F, F + x       - タックル


    超必殺技（パワーゲージをLv.1消費）
    --------
      D, BD, B, x+y  - ワイルドキャノン型マウント（空中のみ）
      D, DF, F, x+y  - ライジングナックル
      D, DF, F, a+b  - ワイルドキャノン（空中のみ）
      F, D, DF  x+a   - スパイア
