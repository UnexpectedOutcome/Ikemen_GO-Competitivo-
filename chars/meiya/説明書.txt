キャラクター名　鳴夜（AIグラップラーVer）
アラド戦記で撮影させてもらったキャラから名前を頂きました

＊注意（敬称略）
ハンゲーム,DNF等
著作権は上記にあります。

操作方法
--------
全て右向きの時の操作です。左向きは移動キーのみ左右逆の操作で行います。

    基本操作
    --------
      鳴夜は和訳カンフーマンを土台として作成させて頂きましたので基本操作は同じです
　　　※その鳴夜を土台として作成させて頂きました。基本操作はたぶん同じです。
      Ｘは弱パンチ・Ｙは強パンチ・Ａは弱キック・Ｂは強キックになっています。
      Ｚは投げ、Ｃは避けです

      各ボタンの説明：
      D - 下
      F - 前
      U - 上
      B - 後
      x - Ｘボタン
      y - Ｙボタン
      z - Ｚボタン
      a - Ａボタン
      b - Ｂボタン
　　　c - Ｃボタン
      s - スタートボタン

      DFは斜め前下、UBは斜め後ろ上など、斜め入力はDFUBを２つ組み合わせる表記になっています。
      空中受け身を出した瞬間、キーを左右どちらかに押していたら
      その方向に少し移動しながら受け身を取ります。
      横に倒れている時、ボタンを連打すれば起き上がりが速くなります。


    通常動作
    --------
      U              - ジャンプ
      UF             - 前ジャンプ
      F              - 前進
      DF             - しゃがむ
      D              - しゃがむ
      DB             - しゃがみ＆しゃがみガード
      B              - 後退＆ガード（空中では空中ガード）
      UB             - 後ジャンプ
      F, F           - ダッシュ
      B, B           - バックステップ
      xy             - 空中受け身

    立ち通常攻撃
    ------------
      X              - 弱パンチ（通常１～４）
      Y              - 強パンチ（ミューズアッパー）
      A              - 弱キック（ローキックというよりボーンクラッシャー）
      B              - 強キック（ハンマーキック）

    しゃがみ通常攻撃
    ----------------
      X              - しゃがみ弱パンチ？（連打すると連続して攻撃）
      Y              - ２段攻撃（２発目中段）
      A              - しゃがみ弱キック
      B              - 足払い

    ジャンプ通常攻撃
    ----------------
      Y              - スパイラルハンマー
      A              - ジャンプキック
      B              - コンドルダイブ（ヒット後のみ上に飛ぶ）

    投げ
    ----
      F + y (密着して) - ロープ
      F + c (密着して) - スープレックス（通常攻撃の最後からキャンセル可能ただしゲージを0.3消費）

    必殺技（コマンド技）
    ------
      D, BD, B + x   - 崩拳　弱
      D, BD, B + y   - 崩拳　強

      D, BD, B + a   - 疾風脚　(空中可）

      C              - ブレイキングエルボー（避けと同時に発動）
      F, D, DF + b   - アッパー

      F, D, DF + x   - 金剛崩　弱
      F, D, DF + y   - 金剛崩　強

      D, DF, F + x   - 念弾（ボタン押しっぱなしでチャージ可能）

      F, F + x       - タックル


    超必殺技
    --------
   パワーゲージ消費 1000
      D, D + z       - マッスルシフト
      
      D, DF, F, x+y  - ライジングナックル
      D, DF, F, a+b  - ワイルドキャノン（空中のみ）
      F, D, DF  x+a  - スパイア
      D, DF, F, y+b  - 投網

      D, BD, B, x+y  - ワイルドキャノン型マウント（空中のみ）

    覚醒技
    ------
   パワーゲージ消費 0～3000
      U, U, D, D + b - 史上最強のローキック



  連続技（コンボ）
  ------

      何でも繋がる勢いです。

■システム解説■
旧鳴夜からかなりシステム面が変化しています。一覧にすると以下の通り。

主なシステム
 ・空中制御をアラドと同様の動きに
 ・スキルのクールタイム的なものを追加
 ・マッスルシフトの追加
 ・クリティカルヒットの追加
 ・覚醒技（史上最強のローキック）追加


サブシステム
 ・ランダムダメージ
 ・ダメージ量に応じて浮き加減調整
 ・ヒット数に応じてダメージ量調整
 ・
