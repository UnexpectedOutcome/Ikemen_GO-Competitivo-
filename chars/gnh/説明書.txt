：削板軍覇 ver1.0 一応正式版
------------------

	とにかく根性だ!！


削板軍覇とは！
--------------
	とある魔術の禁書目録に登場するキャラであり
	学園都市230万人の中でも7人しかいないレベル5(超能力者)である！

	学園都市の調整を受けていない「原石」でありその中でも最大級と目される

	その能力は念動力のようなイメージを受けるがそれだけでは説明できない部分も多い
	学園都市でも解明できていないので超能力かどうかも不明
	とりあえず異常に丈夫でものすごい速くてよくわからない力で吹っ飛ばしたりする

	基本的に熱血根性バカとして描写されていますが内面描写が少ないため深部は不明
	でもたぶんレベル5の中ではわりとまともな人　というか基本いい人　暑苦しいけど

------------------

操作方法
--------
全て右向きの時の操作です。左向きは移動キーのみ左右逆の操作で行います。

    基本操作
    --------
     

      各ボタンの説明：
      D - 下
      F - 前
      U - 上
      B - 後
      x - Ｘボタン
      y - Ｙボタン
      a - Ａボタン
      b - Ｂボタン
      c - Ｃボタン
      z - Ｚボタン
      s - スタートボタン

      DFは斜め前下、UBは斜め後ろ上など、斜め入力はDFUBを２つ組み合わせる表記になっています。
      空中受け身を出した瞬間、キーを左右どちらかに押していたら
      その方向に少し移動しながら受け身を取ります。
      横に倒れている時、ボタンを連打すれば起き上がりが速くなります。


    通常動作
    --------
      U              - ジャンプ：短く押すと小ジャンプになります

      UF             - 前ジャンプ：短く押すと小ジャンプになります

      F              - 前進

      DF             - しゃがむ

      D              - しゃがむ

      DB             - しゃがみ＆しゃがみガード

      B              - 後退＆ガード（空中では空中ガード）

      UB             - 後ジャンプ：短く押すと小ジャンプになります

      F, F           - ダッシュ：ctrlは効きますが止まる時に制動モーションがかかり一瞬ctrlが効かなくなります

      B, B           - バックステップ：開始から空中判定になる迄の間無敵あります

      xy             - 空中受け身：特に何の変哲も無い空中受身。


    特殊動作　　　　　 
    --------
    ジャンプキャンセル - 立ち通常攻撃のみヒット、又はガード時にジャンプでキャンセルできます

　========================================================================================================================
   = 特殊ゲージについて = 
  ========================================================================================================================

　　いわゆる「行動制限ゲージ」として「気合ゲージ」と「根性ゲージ」が存在します(以下　気合G　根性G)
　　この二つは技の使用や特殊システムのコスト等で消費しますが
　　気合Gが切れると技が使えなくなり、根性Gが切れると技使用不可に加えてガードも出来なくなります
　　２つのゲージは時間経過で回復しますが、気合Gは攻撃時、根性Gは喰らい時の間回復しません(ctrlが効く時少し回復速度上昇)
　　更に気合ゲージは攻撃力、根性ゲージは防御力と連動しており、下がれば下がるほど与ダメが減ったり被ダメが増えたりします

　　デフォルトのゲージ上限は気合と根性共に50です

　========================================================================================================================
   = 根性カウントについて = 
  ========================================================================================================================

　　ライフゲージ下あたりにある「根」の文字を便宜上　根性カウント　と言い
　　基本は挑発1回につき1画増え、最大で10溜まります
　　このカウントは　一瞬で特殊ゲージを回復する「気合注入」や「根性注入」に使用する他
　　カウントが多ければ多いほど特殊ゲージの自然回復が早くなります(最大だと一呼吸置けば満タンくらいになります)
　　その瞬間に満タンにするか　回復速度が高い状態を維持するか選んだりしましょう
　　
　　カウント1でもあるとゲージを使い込んだ時にリカバー出来るので安心感が違うと思います

　========================================================================================================================
   = キャンセルシステム = 
  ========================================================================================================================

    基本的に、およそあらゆる技をあらゆる技でキャンセル出来ます
　　キャンセルできるタイミングは大体、攻撃判定後や制動モーション、フォロースルーモーションに入った後からで
　　基本法則として全ての技に行動ランクが設定されており
　　行動ランクが同じ・若しくは高い技へキャンセルする場合は「気合ゲージ」を
　　行動ランクが未満の技へキャンセルする場合は「根性ゲージ」を消費します
　　大方向へキャンセルする場合「気合」小方向へキャンセルする場合「根性」を消費する感じです
　　キャンセル回数によってキャンセルコストが倍増していくのであまり長々とは繋げないです

    必殺技以上の攻撃技は相手に触れずに、いわゆる空振りした状態でキャンセルすると
　　本来のキャンセルコストに加え「行動ランク×5」を固定数値で消費します
　　消費が激しいので暴発防止の為に cボタンを押しながら入力しないと空キャンセル出来ないようになっております


	～キャンセルコストの具体的な計算式～
		
	キャンセルする技のランク(Xとする) <=　キャンセル先の技ランク(Yとする)　の場合、気合ゲージを消費
	計算式は　-(キャンセル回数)*( Y / X ) となります

	X　>　Y　の場合、根性ゲージを消費
	計算式は　-(キャンセル回数)*( X / Y ) となります


　　つまり、ランク1の弱攻撃等からいきなりランク5や6の大技にキャンセルするとコストがモノスゴイです
　　事前に何回かキャンセルしてた場合更にﾏｯﾊです
　　ついでに必殺技以上はランク5以上なので空キャンセルした場合最低でも固定値で25減ります
　　かなりピーキーなキャンセル性能ですがとりあえずこれを基本にしております

      x+y            - 打ち落し：行動ランク3　-気合消費　約6.6%


      a              - 弱キック：行動ランク1　-気合消費　2%
   

      b              - 強キック：行動ランク2　-気合消費　4%

    通常投げ
    ----------------
      F + y  - 投げという名の頭突き

　　　　　     ごく普通の投げですが　この技は行動ランクが存在せず
	　　　 気合や根性が切れてても使う事が出来　また発動に気合を消費しません
	　　　 ただし他の技からキャンセル出来ず、また　他の技でキャンセルする事もできません
	       ちなみに掴みが空振りすると裏拳に移行します

    特殊行動
    ----------------
      c  - ゲージ溜め

		コントロール可能時のみｃボタンを押すとゲージ溜めができます
		気合ゲージ　→　根性ゲージ　→　通常ゲージの順に増加していくため
		気合ゲージや根性ゲージが減ってる時にいきなり通常ゲージを溜める事はできません


      z  - よくわからない力で体を包む

		zを押すことにより好きなタイミングで攻撃を無効化するシールドを展開します
		ほぼすべての攻撃を防ぎますが　維持するのに気合ゲージをすごい勢いで消費し
		攻撃を受けると根性ゲージが減ります
		攻撃を無効化すると気合ゲージの消費が和らぐので
		ギリギリまで引き付けてタイミング良く無効化しましょう


      c+z  - すごいガード：行動ランク4
		
		c+zを押し続ける事によりガードを維持します
		ほぼすべての攻撃を防ぎますが　維持するのに気合ゲージを徐々に消費し
		攻撃を受けると根性ゲージが減ります
		ただし攻撃を受けると気合ゲージが少し回復し
		連続で攻撃を防ぐと根性ゲージの減少率が低くなります
		

      s  - 挑発

		およそあらゆる地上技からキャンセルして挑発できますが
		全体フレームがそれなりに長い上に他の技でキャンセルできません
		虹色の爆発が出たタイミングで根性カウントが+1されます


     y + b   - ガードキャンセル攻撃
		
		よく分からない爆発を起こして周囲の相手を吹っ飛ばします
		地上ガード中に限り　根性ゲージを最大値の半分と通常ゲージ500を消費して発動出来ます
		コストが確保されていない場合発動できません
		


    ダッシュ制動攻撃 

		ダッシュ開始から10F以降に停止すると制動モーションになりますが
		制動モーション中5F以降に攻撃ボタンを押すと対応した攻撃が出ます
		気合ゲージや根性ゲージが無くても発動出来ます
    ----------------
      x              - 払い　　　：行動ランク無し　-気合消費　無し


      y              - グーパン　：行動ランク無し　-気合消費　無し


      a              - 退避キック：行動ランク無し　-気合消費　無し
   

      b              - 踏みつけ　：行動ランク無し　-気合消費　無し



    攻撃不能時限定当身 

		ゲージを使い込んでしまい　ほぼ攻撃が出せなくなった時のみ限定の当身
		基本的にダメージは与えられません
    ----------------
      x or a         - 後退当身　：行動ランク無し　-気合消費　無し
			下がりながら相手の攻撃に当身を取ります(飛び道具不可)
			当身が成功すると相手をそのまま後ろにブン投げ叩きつけます
			ダメージは無いですが　有利時間を確保してゲージ溜めや挑発を狙いましょう
			
      y or b         - 前進当身　：行動ランク無し　-気合消費　無し
			前進しながら相手の攻撃に当身を取ります(飛び道具可)
			当身が成功すると一瞬で相手の真後ろに回りつつも不利時間は発生しません
			特殊ゲージ復帰直前に狙ったり、移動後に後退当身や正拳突き当身を狙ったりしましょう
   

      a + b
     　or
      x + y          - 正拳突き当身　：行動ランク無し　-気合消費　無し
			腰を落として片手で相手の攻撃を受け止めて正拳突きで反撃します
			ダメージはありませんが、攻撃が当たると気合と根性ゲージが全回復し
			おまけに根性カウントも+1されます
			超おいしいので積極的に狙いましょう

   = 必殺技 = これだけでわりと戦えると思う

      D, DF, F + x   - すごいパンチ・物理　：行動ランク5　-気合消費　10%
	地上限定
　　　			発動遅めですが空中ガード不可且つ　Xボタンを押し続ける事で根性Gを消費して溜める事ができ
			溜める程威力が上がり、最大溜めで相手のガードを割れます
			また、最大溜めがガードされなかった場合相手は壁バウンド喰らいになります　
			振りかぶりポーズ中に↓で技自体を解除できます
			気合ゲージによる攻撃力補正を受けにくいです


      D, DF, F + y   -  すごいパンチ・特殊　：行動ランク5　-気合消費　10%
	地上限定　
　　　			発動遅めですが目に見えない飛び道具で攻撃します
			Yボタンを押し続ける事で根性Gを消費して溜める事ができ
			溜める程相手の吹っ飛び高が上がり、最大溜めでガード不能になります　
			振りかぶりポーズ中に↓で技自体を解除できます
			気合ゲージによる攻撃力補正を受けません
			溜めモーション中に飛び道具を受けると無効化した上で強制的にすごパが発動します


      F, B + x      - すごパ物理・連打　：行動ランク5　-気合消費　10%
	地上限定
　　　			発動遅めですがものすごい勢いで相手をタコ殴りにします　10発くらい
			たまに中段やら空中ガード不能が混じりますが基本立ちガード安定
			事前に他の技を当てておらず　なお且つ最後の10発目が当たれば
			相手は壁バウンド喰らいになります　
			気合ゲージによる攻撃力補正を受けにくいです


      F, B + y      -  すごパ特殊・連打　：行動ランク5　-気合消費　10%
	地上限定　
　　　			発動遅めですが小さめのすごパ・特で連続射撃します　10発くらい
			ダメージは単発のすごパ・特と同じくらいですが攻撃判定時間が長めです
			拳部分が当たれば多少威力が上乗せされます　
			気合ゲージによる攻撃力補正を受けません



      D, DB, B + x   - 打ち払い　：行動ランク5　-気合消費　10%
	地空兼用	　　　
　　　			威力低めですが裏拳や蹴りで素早く打ち払い距離を少し詰めます
			タイミングによっては飛び道具を打ち払えます(というかそっちがメインです)


      D, DB, B + y   - マッハ投げ　：行動ランク5　-気合消費　10%
	地上限定
　　　			100F程の準備モーションの後　終了時にUを押してると空投げ構え
			押してないと地上投げ構えに移り、どちらも20F後から掴み判定が発生します
			空投げは立ちと空中の敵　地上投げはしゃがみと立ちの相手を掴めます

      D, DF, F + b   - すごい震脚・強　：行動ランク5　-気合消費　10%
