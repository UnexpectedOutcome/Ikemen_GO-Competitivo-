
～各種設定変更方法～

「oyashirorika_-3_AI.cns」ファイル内の記述を変更することで
以下の項目について、設定を変更することができます。

　- AIのダメージタッチ使用頻度
　- メタゲージ増加速度
　- タッチゲージ増加速度


変更の仕方は[Statedef -3]の一番最初の方に、

;■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■
;■各種設定
:■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■

[State -3];AI用ダメージタッチ使用頻度
type = Varset
trigger1 = 1
v = 32
value = 2
;0=使用しない、1=使用頻度低、2=使用頻度中（デフォルト値）、3=使用頻度高

[State -3];メタゲージ増加速度
type = Varset
trigger1 = 1
v = 33
value = 1
;1=遅い（デフォルト値）、2=普通、3=速い

[State -3];タッチゲージ増加速度
type = Varset
trigger1 = 1
fv = 20
value = 2
;1=遅い、2=普通（デフォルト値）、3=速い



と記載されているので、Value値を任意の値に変更してください。
