4.システム
￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣
・通常投げ１              : 相手に接近してからY+B．6or4で投げる方向を決定します．
                            ■NBC，ARRANGEモードで使用可能．

・通常投げ２              : 相手に接近してから6or4+YorB．
                            ■02UM，XIモードで使用可能．

・フロントステップ        : 66．そのまま6を押し続けるとランに変化します．
                            ■NBC，ARRANGEモードで使用可能．

・タクティカルステップ    : X+A or C．パワーゲージを0.5本消費してフロントステップを
                            行います．
                            ■NBC，ARRANGEモードで使用可能．

・ACタクティカルステップ  : 地上の通常攻撃がヒットしている状態で，X+A or C．
  (アタックキャンセル)      通常攻撃をキャンセルしてタクティカルステップを行います．
                            パワーゲージを１本消費．
                            ■NBC，ARRANGEモードで使用可能．

・GCアタック              : ガード中にZ．パワーゲージを１本消費．
  (ガードキャンセル)
                            ■NBCモードで使用可能．

・GCステップ              : ガード中に66．パワーゲージを0.5本消費．
                            ■NBC，ARRANGEモードで使用可能．

・オートチャージ          : ラウンド開始から８秒後，自動的に発動．
                            少しずつパワーゲージを増加します．
                            ■NBC，ARRANGEモードで使用可能．

・ふっとばし攻撃          : Y+B．Zでも可．
                            ■02UM，XI，ARRANGEモードで使用可能．
                            ※ARRANGEモードはZボタンのみ．

・GCふっとばし攻撃        : ガード中にY+B．Zでも可．パワーゲージを１本消費．
                            ■02UM，XI，ARRANGEモードで使用可能．
                            ※ARRANGEモードはZボタンのみ．

・緊急回避                : 6or4+(X+A)．
                            ■02UM，XI，ARRANGEモードで使用可能．

・クイック緊急回避        : 通常攻撃か特殊攻撃中に6or4+(X+A)．パワーゲージを１本消費．
                            ■02UM，ARRANGEモードで使用可能．

・GC緊急回避              : ガード中に6or4+(X+A)．パワーゲージを１本消費．
                            ■02UM，XI，ARRANGEモードで使用可能．

・MAX発動                 : Y+A．Cでも可．パワーゲージを１本消費．
                            ■02UM，ARRANGEモードで使用可能．

・クイックMAX発動         : 通常攻撃か特殊攻撃中にY+A．Cでも可．パワーゲージを２本消費．
                            ■02UM，ARRANGEモードで使用可能．

■特殊攻撃
・イカルスの靴 : 22B

・特殊技（※1）: 6Y

■必殺技
・ハマドリュアスバスター     : 236X or Y．空中可．スーパーキャンセル可．バックステップ中に使用可（※2）

・ネプチューンキラー         : 623A or B．

・モーニングスターアタック   : 214X．
・モーニングスタークラッシュ : 214Y．

・ライオンズシールド         : 63214A or B．

・プカプカホバリング         : 空中でA+B．イカルスの靴中に使用可．バックステップ中に使用可（※2）
  ｜                           MAX発動時，コマンド受付時間とキャンセルポイントが変わる
  ├ユニコーンホーン         : プカプカホバリング中に，X or Y．
  ├テュポーンスイング       : プカプカホバリング中に，A．
  └ホバリング解除           : プカプカホバリング中に，B．

・ライフフラワー／
    薬草科体力目コルプス     : 22X+Y．ライフフラワー付近にいるキャラクターの体力
                               を400増加します．
    薬草科気力目プネウマ     : 22A+B．ライフフラワー付近にいるキャラクターの
                               パワーゲージを900増加します．
    薬草科爆弾目ピュロボロス : 22Y+A．ガード不可ダメージ（敵味方問わず）．

■超必殺技
・ポセイドン・レイジ         : 2141236A or B．パワーゲージを１本消費．

・ヘブンズ・ゲイト           : 641236X or Y．パワーゲージを１本消費．

・炎の杖                     : 236236X．パワーゲージを１本消費．空中可（※2）
  ├フライングファイヤー     : 炎出現中に，236236X．空中可（※2）
  └ファイヤーストーム       : 炎出現中に，236236Y．パワーゲージを１本消費．空中可（※2）

・風の杖                     : 236236Y．パワーゲージを１本消費．空中可（※2）
  ├フライングハリケーン     : 竜巻出現中に，236236Y．空中可（※2）
  └ストームファイヤー       : 竜巻出現中に，236236X．パワーゲージを１本消費．空中可（※2）

・ペガサス☆ファンタジー     : 2363214A or B．
                               NBC，02UMモードは，パワーゲージを３本消費．（※3）
                               XI，ARRANGEモードは，パワーゲージ２本消費．

  ※1，NBCモード以外で使用可能
  ※2，ARRANGEモード限定
  ※3，MAX超必殺が未実装のため，体力が300以下ではなくても使用可能です．
