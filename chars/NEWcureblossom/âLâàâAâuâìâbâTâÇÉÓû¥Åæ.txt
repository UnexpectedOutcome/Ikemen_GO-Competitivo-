キュアブロッサム（2011/6/14更新版）
------------------
　●「ハートキャッチプリキュア！」より、主人公のキュアブロッサムです。
　　製作途中で、調整不足なところもあると思いますが、楽しんでいただけたら幸いです。

　●WIN版専用キャラです。

カラーについて
--------------
キャラ選択時に押したボタンによりカラーが変わります。（能力は全て同じです）
・aボタン：通常カラー　
・bボタン：マリンカラー
・cボタン：サンシャインカラー
・xボタン：ムーンライトカラー
・yボタン：ダークプリキュアカラー
・zボタン：つぼみカラー


操作方法
--------
全て右向きの時の操作です。左向きは移動キーのみ左右逆の操作で行います。

    基本操作
    --------
     
      各ボタンの説明：
      D - 下
      F - 前
      U - 上
      B - 後
      x - Ｘボタン
      y - Ｙボタン
      a - Ａボタン
      b - Ｂボタン
　　　c - Ｃボタン
      s - スタートボタン
　　　パワー溜め　：Ａ＋Ｘボタンを押しっぱなし
      シールド　　：Ｚボタン（空中でも可能）

      DFは斜め前下、UBは斜め後ろ上など、斜め入力はDFUBを２つ組み合わせる表記になっています。
      空中では、一回だけ空中ジャンプが可能です。
      空中受け身を出した瞬間、キーを左右どちらかに押していたら
      その方向に少し移動しながら受け身を取ります。
      横に倒れている時、ボタンを連打すれば起き上がりが速くなります。
      スタートボタンを押せば相手を挑発します。


    通常動作
    --------
      U              - ジャンプ
      UF             - 前ジャンプ
      F              - 前進
      DF             - しゃがむ
      D              - しゃがむ
      DB             - しゃがみ＆しゃがみガード
      B              - 後退＆ガード（空中では空中ガード）
      UB             - 後ジャンプ
      F, F           - ダッシュ
      B, B           - バックステップ
     (空中で)F, F    - 前方エアダッシュ
　　 (空中で)B, B    - 後方エアダッシュ
      xy             - 空中受け身

    特殊動作
    --------
      (ライフ50％以下で)F/B + s  -「私、堪忍袋の緒が切れました！！」
                                   :パワーゲージ自動回復、ライフ200回復、
　　　　　　　　　　　　　　　　　　攻撃力・防御力1.2倍

    立ち通常攻撃
    ------------
      X              - 弱パンチ
      Y              - 強パンチ
      A              - 弱キック
      B              - 強キック

    しゃがみ通常攻撃
    ----------------
      X              - しゃがみ弱パンチ
      Y              - しゃがみ強パンチ
      A              - しゃがみ弱キック
      B              - 足払い

    ジャンプ通常攻撃
    ----------------
      X              - ジャンプ弱パンチ
      Y              - ジャンプ強パンチ
      A              - ジャンプ弱キック
      B              - ジャンプ強キック

    投げ
    ----
      F/B + y (密着して) - ブロッサムダブルインパクト

    必殺技
    ------
      D, DB, B + x   - 突き飛ばし
      D, DB, B + y   - ブロッサムインパクト
      D, DB, B + xy  - ブロッサムインパクト・EX :(パワーゲージを330ポイント消費)

     (空中で)D, DB, B + x   - 空中ブロッサムインパクト・弱
     (空中で)D, DB, B + y   - 空中ブロッサムインパクト・強
     (空中で)D, DB, B + xy  - 空中ブロッサムインパクト・EX:(パワーゲージを330ポイント消費)

      D, DF, F + x   -ブロッサムシュート・弱
　　　D, DF, F + y   -ブロッサムシュート・強
      D, DF, F + xy  -ブロッサムシャワー

      D, DF, F + a   - 弱・蹴り上げ    :中段攻撃
      D, DF, F + b   - 強・蹴り上げ　　:中段攻撃
      D, DF, F + ab  - 速い蹴り上げ 　 :中段攻撃(パワーゲージを330ポイント消費)

      F, D, DF + a   - 弱・上昇蹴り
      F, D, DF + b   - 強・上昇蹴り
      F, D, DF + ab  - 速い上昇蹴り　　:(パワーゲージを330ポイント消費)
      飛んでる最中にＡかＢを押せば追加攻撃が可能

      D, DB, B + a/b - 急降下キック

    超必殺技
    --------
　　（パワーゲージを1000ポイント消費）
      a+c　　　- ブロッサムスクリューパンチ
      D, DF, F, D, DF, F + x/y　または F+a+c  - レッドの種
      D, DB, B, D, DB, B + x/y　または B+a+c  - 強い蹴り上げ　;中段攻撃

　　（パワーゲージを2000ポイント消費）
　　　b+c　　　- プリキュアピンクフォルテウェーブ　  :相手のパワーゲージを少し減少させます。
      F/B+b+c  - レッドの種→ブロッサムおしりパンチ

    （パワーゲージを3000ポイント消費）
　　　x+c　　　- プリキュアフローラルパワーフォルテッシモ:技を出している間は無敵です。
　　　　　　　　　　　　　　　　　　　　　　　　　   :相手のパワーゲージを減少させます。

    （パワーゲージを4000ポイント消費）
　　　y+c  　　- プリキュアシャイニングフォルテッシモ:技を出している間は無敵です。
　　　　　　　　　　　　　　　　　　　　　　　　　   :相手のパワーゲージを多く減少させます。

    （パワーゲージを5000ポイント消費）
　　  a+b+c  　- プリキュアハートキャッチオーケストラ:ガード不可の全画面攻撃です。

    ストライカー
    ------------
　　○キュアマリン
      D, DF, F + c - マリンダイブ→マリンシュート(パワーゲージを500ポイント消費)

　　○キュアサンシャイン
      D, DB, B + c - サンフラワーイージス　　　　(パワーゲージを500ポイント消費)
　　　　　　　　　 　単純な飛び道具を防ぎ、1度だけ、触れた相手を弾きます。

　　○キュアムーンライト
      D, D + c     - ムーンタクト　　　　　　　　(パワーゲージを500ポイント消費)
 
　　○キュアメロディ＆キュアリズム(超必殺技)
      F/B+x+c     - プリキュアパッショナートハーモニー
　　　　　　　　　　　　　　　　 　　　　　　　　(パワーゲージを3000ポイント消費)
