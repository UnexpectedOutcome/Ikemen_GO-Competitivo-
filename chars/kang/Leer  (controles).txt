  Controles
  --------

    Controles Básicos
    --------------


      D - Abajo
      F - adelante
      U - arriba
      B - atras
      x - button X (Puño ligero)
      y - button Y (Puño medio)
      z - button Z (Puño Fuerte)
      a - button A (patada ligera)
      b - button B (patada media)
      c - button C (patada Fuerte)
      s - Start (burla)

      Mismos botones y características en golpes Aéreos y Agachado.

    Movimientos Standard 
    -----------------
      U              - Salta
      UF             - Salta hacia adelante
      F              - hacia adelante
      D              - abajo (cierra la trompa)
      DB             - trompa cerrada y se cubre
      B              - hacia atras o cubre
      UB             - Salta hacia atras
      F, F           - corre
      B, B           - Se retira hacia atras
 

    Special Attacks
    ---------------
      D, DF, F + x   - Disparo Congelante (freeze)
      D, DF, F + y   - Disparo Caliente  (burn)
      D, DF, F + z  - Disparo Eléctrico (usa 1/3 power bar)
      D, DF, F + a  - Tabla con Clavo
      D, DF, F + b  - Ventiláculo

      F, F,+ x   - Uppercut (ligero)
      F, F,+ y   - Uppercut (medio)
      F, F,+ z  - Uppercut (fuerte) (usa 1/3 power bar)

      D, DB, B + x   - Escupe una calavera
      D, DB, B + y   - Escupe un Alien (especie de Roger)
      D, DB, B + z  - Mordidota (usa 1/3 power bar) 

     
    Hyper Attacks (Usan 1 power bar)
    -------------
      D, DF, F, + xy  - Salto Ninja
      D, DF, F, + yz  - Ataque Vikingo
      D, DB, B,+ ab  - Tentáculos  bajo tierra
      D, DB, B,+ bc  - Succiona masa (Midnight Bliss)
