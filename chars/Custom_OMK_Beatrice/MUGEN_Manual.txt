I am trying to mugenize a custom OMK Beatrice recently.

Plan A:  add Beatrice to Boomer's Lucifer and make them Touch-able like in the source game
After working on Plan A for a while.............found it was just too hard to an un-skillful me!
So.......then switch to Plan B.

Plan B:  edit Boomer's Battler to make a stand-alone Beatrice.

If you are not familiar with OMK Beatrice, then please read the enclosed Ougon Musou Kyoku-Beatrice - Mizuumi Wiki.mht
* please use Internet Explorer or Google Chrome to open the .mht file......

Not using Boomer's default button layout any more.

Now using this button layout:
x: Weak attack
y: Medium attack
z: Strong attack
a: Touch
b: Appeal
c: Meta shortcut

throw:  close to P2, y+z
SP supers:  special commands and x+y
Meta:  x+y+z
