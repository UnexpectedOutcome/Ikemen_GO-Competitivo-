Some Gameplay
 
Due to the large usage of power on the moves, Nami's power would keep increasing every few seconds.
 
Cat Burglar is a skill for Nami to steel the power from the enemy, and it can't be guarded if you steals from behind.
 
Mirage Tempo is not unhitable all the time, it still has 20% chance can be hit by enemy, but when the time Nami is in guarding state (holding back), it would be 100% unhitable. 
When in Mirage Tempo mode, the power supposed to be add on Nami's moves would decrease 50%, let's say if nami performs a normal attack then she would gain 36 power in normal mode, but in Mirage Tempo mode she would only gain 18 power.
You can cancel Mirage Tempo manually. 
 
Knot of Wind is a skill which react to the weather ball and your enemy, and also it can react with Thunderbolt = Tempo LV2 (LV2 Super Attack).
