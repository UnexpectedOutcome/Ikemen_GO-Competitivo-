Description

This is Virgilia from Ougon Musou Kyoku
The character is made to be almost identical to what she is in the original game.
The original game uses a tag-team battle system in which the player can control two different characters and
switch between them in the battle. Due to the limitation of Mugen system, the character is made to change with 
herself.
AI is implemented, it is simple but may be hard to beat.
Changing the AI level in mugen will not have any effect on the AI.

This character can only run on mugen 1.1 or above version
This character is made for 1VS1, many bugs will occure if you put her in simul mode.

The character can fit in both 4:3 and 16:9 resolution, if you want to use the character in 16:9
resolution, please open "virgilia.def", change "localcoord = 640,480" to "localcoord = 852".
The recommended setting of using this character is a 16:9 stage with zoomin 1-1.2, zoomout 0.7-0.9.

How to config the character

If you want to change the damage done by Virgilia, you can open "Virgilia.cns", change the value of 
attack. A higher value of attack will make her do more damages and vice versa.
Default is 100. The damage is calculated using 5600(Battle's life) as the standard.


For other options, please open "option.txt". You will see the following codes:

[State 0, Max SP]
type = PowerSet
trigger1 = var(14) = 0 && movetype = I && stateno != [7500,7599]
trigger1 = (0)←set this to 1 will make the character have maximum SP when she is not in attack state
trigger1 = var(18):=powermax
trigger2 = (0)←set this to 1 will make the character have infinite SP
trigger2 = var(18):=powermax
value = powermax
ignorehitpause = 1

[State 0, Get SP]
type = VarSet
trigger1 = 1
fv = 8
value = (1)←This value affect how much SP Virgilia will get when she hit the opponent or the attack is guarded, default value is 1
ignorehitpause = 1

[State 0, Give SP]
type = VarSet
trigger1 = 1
fv = 9
value = (1)←This value affect how much power the opponent will get when Virgilia hit the opponent or the attack is guarded, default value is 1
ignorehitpause = 1

[State 0, Refill Meta]
type = VarSet
triggerall = var(39) = 0
trigger1 = var(14) = 0
trigger1 = (0)←set this to 1 will make the meta gauge full when the character is not in attack state
trigger2 = (0)←set this to 1 will make the meta gauge full as long as the character is not in the meta world
fv = 10
value = 1
ignorehitpause = 1

[State 0, Refill Meta]
type = VarSet
trigger1 = 1
fv = 11
value = (1)←This value affect the speed of refilling the character's meta gauge
ignorehitpause = 1

[State 0, Stun Constant]
type = VarSet
trigger1 = 1
fv = 5
value = (1)←This value affect how often the character put enemy into the stun, a higher value makes her easier to put enemy into stun and vice versa. You can also set this value to 0 to disable stunning, default value is 1
ignorehitpause = 1

[State 0, damage reduction]
type = VarSet
trigger1 = 1
v = 19
value = (1)←Set this value to 0 to disable damage reduction. If you set it to -1, the character will do more when number of hit increases.
ignorehitpause = 1

[State 0, juggle]
type = VarSet
trigger1 = 1
v = 23
value = (0)←Set this value to 1 to enable the character hit the opponent in the air for infinite time
ignorehitpause = 1

[State 0, Set Off]
type = VarSet
trigger1 = 1
v = 42
value = (0)←Set this value to 1 to enable the set off, bugs may appear...
ignorehitpause = 1

[State 0, Princess Mode]
type = VarSet
trigger1 = 1
v = 50
value = (0)←Set this value to 1 to enable princess mode
ignorehitpause = 1

[State 0, meta]Disable Meta Reversal and Meta Re-objection
type = VarSet
trigger1 = 1
v = 43
value = (0)←Set this value to 1 to disable Meta Reversal and Meta Re-objection
ignorehitpause = 1

[State 0, bgm]Special Ko BGM which will be played when Virgilia finishes the opponent by Magic Item Show or Odin
type = VarSet
trigger1 = 1
v = 44
value = (0)←0=No bgm
             1=黄金夢想曲～金色の血に染まる前に～（instrumental）
             2=黄金夢想曲X～黄金の奇跡を叶えるまで ～（instrumental）
             3=Golden Show Time! ～黄金夢想曲CROSS†～（instrumental）
ignorehitpause = 1


[State 0, gauge pos]
type = VarSet
trigger1 = 1
v = 45
value = (0)Change this value to adjust the height of the meta and SP gauge
ignorehitpause = 1
