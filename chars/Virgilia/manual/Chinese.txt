注意事項

這是根據PC版黄金夢想曲†CROSS v2.31的角色ワルギリア制作的人物，目標是完全還原原作，完成度為99％。
原作是兩人一組的格鬥方式，由於Mugen的限制，變成了自己換自己。
人物搭載了簡易AI，強度是強級左右，無AI等級可調。



注意這人物不能在win和1.0的Mugen運行，另外在制作時只考慮了1VS1的情況，在Simul模式會出現嚴重的BUG。
人物適應4:3和16:9的畫面，如要在16:9的畫面使用，請打開”virgilia.def”，把"localcoord = 640,480"改為"localcoord = 852"。
在zoomin值為1-1.2，zoomin值為0.7-0.9的16:9場景上使用效果為最佳。

性能調整

調整整體傷害
打開"Virgilia.cns"，修改"attack = "後的數字。初始值為100，傷害是以原作5600傷害(戰人的HP)為十割的傷害計算。
較高的數字表示會打出更高的傷害


其他選項
打開”option.txt"，修改()內的數字
[State 0, Max SP]
type = PowerSet
trigger1 = var(14) = 0 && movetype = I && stateno != [7500,7599]
trigger1 = (0)←非攻擊狀態補滿SP，1=on,2=off
trigger1 = var(18):=powermax
trigger2 = (0)←無限SP，1=on,2=off
trigger2 = var(18):=powermax
value = powermax
ignorehitpause = 1

[State 0, Get SP]打氣速度
type = VarSet
trigger1 = 1
fv = 8
value = (1)←大於1的數字使集氣更快，少於1的數字使集氣變慢
ignorehitpause = 1

[State 0, Give SP]
type = VarSet
trigger1 = 1
fv = 9
value = (1)←大於1的數字使攻擊時給對手的能量變多，少於1的數字使攻擊時給對手的能量變少
ignorehitpause = 1

[State 0, Refill Meta]
type = VarSet
triggerall = var(39) = 0
trigger1 = var(14) = 0
trigger1 = (1)←非攻擊狀態補滿Meta槽，1=on,2=off
trigger2 = (0)←Meta值自動補滿，1=on,2=off
fv = 10
value = 1
ignorehitpause = 1

[State 0, Refill Meta]Meta值回復速度
type = VarSet
trigger1 = 1
fv = 11
value = (1)←大於1的數字增加回復速度，少於1的數字減少回復速度
ignorehitpause = 1

[State 0, Stun Constant]氣絕值補正
type = VarSet
trigger1 = 1
fv = 5
value = (1)←大於1的數字使對方更容易氣絕，少於1的數字使對方更難氣絕，0則對方不會氣絕
ignorehitpause = 1

[State 0, damage reduction]傷害修正
type = VarSet
trigger1 = 1
v = 19
value = (1)←初始值為1(連段傷害會不斷減少)，設為0則連段傷害不會減少，-1為逆修正(連段傷害不斷增加)
ignorehitpause = 1

[State 0, juggle]解除空連限制
type = VarSet
trigger1 = 1
v = 23
value = (0)←1=on,0=off
ignorehitpause = 1

[State 0, Set Off]攻擊相殺
type = VarSet
trigger1 = 1
v = 42
value = (0)←1=on,0=off, 打開後可能會有BUG
ignorehitpause = 1

[State 0, Princess Mode]公主模式
type = VarSet
trigger1 = 1
v = 50
value = (0)←1=on,0=off
ignorehitpause = 1

[State 0, meta]禁止對手反論
type = VarSet
trigger1 = 1
v = 43
value = (0)←1=on,0=off
ignorehitpause = 1

type = VarSet
trigger1 = 1
v = 44
value = (0)←0=無
             1=黄金夢想曲～金色の血に染まる前に～（instrumental）
