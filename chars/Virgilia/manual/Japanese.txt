注意事項

このキャラは PC版 黄金夢想曲†CROSS v2.31 仕様のキャラです。原作再現を目指してこのキャラを作ってみた。
このキャラはMUGEN1,1専用です。WINや1.0など旧バージョンのＭＵＧＥＮでは使用できません。ご注意ください。
完成度は99％です。
簡易AIを搭載しています。
原作では選択した控えのパートナーと交代しますが、このキャラは自分と交代しています。

このキャラはSimulモードにプレイすることはできますか、多いなバグを出っています。

16：9画面で遊ぶ場合は”virgilia.def”を開きで
”localcoord = 640,480"を”localcoord = 852"て変更してください。

zoomin＝1~1.2、 zoomout＝0.7~0.9の16：9ステージは推奨します。

キャラの調整について

"Virgilia.txt" を開きで、"attack = 100"の”100”を調整して、キャラの攻撃力を変更できる。
デフォルトは100、ダメージは原作の5600ダメージ(戦人のHP値)がＭＵＧＥＮでほぼ十割となる計算です。

そして”option.cns"を開きで、他の性能が調整できます。設定方法は「←」の指す()内を変更します。
[State 0, Max SP]
type = PowerSet
trigger1 = var(14) = 0 && movetype = I && stateno != [7500,7599]
trigger1 = (1)←SPゲージ最大、0でoff。1でon
trigger1 = var(18):=powermax
trigger2 = (0)←SPゲージ無限、0でoff。1でon
trigger2 = var(18):=powermax
value = powermax
ignorehitpause = 1

[State 0, Get SP]SP獲得補正
type = VarSet
trigger1 = 1
fv = 8
value = (1)←デフォルトは1、>1でSP獲得が増加、<1でSP獲得が減少
ignorehitpause = 1

[State 0, Give SP]与えるSP補正
type = VarSet
trigger1 = 1
fv = 9
value = (1)←デフォルトは1、>1で相手に与えるSP量が増加、<1で相手に与えるSP量が減少
ignorehitpause = 1

[State 0, Refill Meta]
type = VarSet
triggerall = var(39) = 0
trigger1 = var(14) = 0
trigger1 = (1)←メタゲージ最大、0でoff。1でon
trigger2 = (0)←メタゲージ無限、0でoff。1でon
fv = 10
value = 1
ignorehitpause = 1

[State 0, Refill Meta]メタゲージ回復スペード
type = VarSet
trigger1 = 1
fv = 11
value = (1)←デフォルトは1、>1でスペードが増加、<1でスペードが減少
ignorehitpause = 1

[State 0, Stun Constant]気絶補正
type = VarSet
trigger1 = 1
fv = 5
value = (1)←デフォルトは1、>1で相手を気絶しやすい、<1で相手を気絶しにくい、0で相手を気絶しない
ignorehitpause = 1

[State 0, damage reduction]コンボ補正
type = VarSet
trigger1 = 1
v = 19
value = (1)←デフォルトは1、0でコンボ補正無し、-1で逆修正
ignorehitpause = 1

[State 0, juggle]juggle無視
type = VarSet
trigger1 = 1
v = 23
value = (0)←0でoff。1でon
ignorehitpause = 1

[State 0, Set Off]相殺
type = VarSet
trigger1 = 1
v = 42
value = (0)←0でoff。1でon。バッグはあるかも知れない
ignorehitpause = 1

[State 0, Princess Mode]プリンセスモード
type = VarSet
trigger1 = 1
v = 50
value = (0)←0でoff。1でon
ignorehitpause = 1

[State 0, meta]メタ返し禁止
type = VarSet
trigger1 = 1
v = 43
value = (0)←1でon,0でoff
ignorehitpause = 1

[State 0, bgm]処刑用BGM
type = VarSet
trigger1 = 1
v = 44
value = (0)←0=無い
             1=黄金夢想曲～金色の血に染まる前に～（instrumental）
             2=黄金夢想曲X～黄金の奇跡を叶えるまで ～（instrumental）
             3=Golden Show Time! ～黄金夢想曲CROSS†～（instrumental）
ignorehitpause = 1
