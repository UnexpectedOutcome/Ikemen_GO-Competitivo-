Next, add the follow codings into a helper state which the helper is created at the beginning of the fight
and the helper is able to move in pause.(e.g. AI helper/helper for power guage...)
You may need to change the code a little bit to fit into your character.

;Meta Reversal
[State 0]
type = Explod
triggerall = enemy,authorname = "Eiton"
triggerall = root,power >= root,powermax*0.4
triggerall = !numexplod(75025)
triggerall = enemy,Stateno = 7500 || enemy,Stateno = 7520
trigger1 = !root,AIlevel
trigger1 = root,command = "a" && root,command = "b" && root,command = "c"
trigger2 = AIlevel
trigger2 = 0;set the condition you like to let AI use the Meta Reversal and Meta Re-objection
anim = 9999
ID = 75025
pos = 0,0
postype = p2 
facing = 1
removetime = -1
bindtime = 1
scale = 1,1
sprpriority = -10
ownpal = 1
