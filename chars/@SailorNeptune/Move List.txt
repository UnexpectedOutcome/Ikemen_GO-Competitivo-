A = --
B = Strong Kick (Patada Fuerte)
C = Strong Punch (Golpe Fuerte)

X = Light Kick (Patada Devil)
Y = Light Punch (Golpe Devil)
Z = --

U = UP (Arriba)
B = Back (Atras)
D = Down (Abajo)
F = Front (Adelante)

P1= player 1 (Jugador 1)
P2= player 2 (Jugador 2)

:¨:..:¨::¨:..:¨::¨:..:¨:
Movimientos Normales.
:¨:..:¨::¨:..:¨::¨:..:¨:

AGARRE: F + B ó C (cerca P2)

:¨:..:¨::¨:..:¨::¨:..:¨:
Movimientos Especiales.
:¨:..:¨::¨:..:¨::¨:..:¨:

MAREMOTO DE NEPTUNO LV1: B,BD,D,DF,F + C ó Y, (PUEDES CONTROLAR EL MARAMOTO, OPRIMIENDO U ó D)
DRAGON DE MAR LV1: F,D,DF,F + C ó Y
TIFON DE MAR: D,DB,B + B ó X 
CACHETADAS: F,FD,D,DB,B + C ó Y 
REFLECCION SUBMARINA LV1: B,BD,D,DF,F + B ó X
GOLPE DE OLA: F,D,DF,F + B ó X

:¨:..:¨::¨:..:¨::¨:..:¨:
Movimientos Supers.
:¨:..:¨::¨:..:¨::¨:..:¨:

MAREMOTO DE NEPTUNO LV2: F,B,BD,D,DF,F + C ó Y
REFLECCION SUBMARINA LV2: D,DB,B,BD,D,DF,F + B ó X
DRAGON DE MAR LV2: D,DF,F * 2 + C ó Y
NEPTUNO PERFORMANCE LV1: D,DF,F * 2 + B ó X
ILUSION DE SIRENA: D,DB,B * 2 + B ó X

:¨:..:¨::¨:..:¨::¨:..:¨:
Movimientos Desesprados.
:¨:..:¨::¨:..:¨::¨:..:¨:

MAREMOTO DE NEPTUNO LV3: D,DF,F * 2 + CY
NEPTUNO PERFORMANCE LV2: D,DF,F * 2 + BX
TSUNAMI: D,DB,B * 2 + BX
ARMADURA DE MEDUSA: D,DB,B * 2 + CY
