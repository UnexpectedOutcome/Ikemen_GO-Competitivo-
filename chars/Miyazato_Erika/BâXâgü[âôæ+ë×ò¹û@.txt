============================================================================
＜Bストーンについて＞
・Bストーンとは、Bパワーを放出する結晶で、これが各自の特殊能力の源となっています。
・Bストーンは攻撃がヒットした時に放出され、獲得するとゲージが増加します(大:30,小10)。
・敵味方関係なく獲得可能ですが、未対応の敵が取得した場合は、再度攻撃が当たった時に増加となります。
　対応させる事でこれを即時増加させる事ができます。
・対応はバックアップを取るなどして、各自の責任に於いて行って下さい。

＜対応方法＞
１．Config.txt（1.0使用時はConfig1.0.txt）内にあるBストーン対応の項目で、対応させたいキャラ名を追加して下さい。

 {対応例}
;--------------------------------------------------------------------------
;<<OPTION-A6: Bストーン対応>>
[state a, B Stone]
type = VarSet
var(36) = 10
triggerall = numenemy
trigger1 = enemy,authorname = "Songfu"
trigger2 = enemy,name = "nameA"		;対応させたいキャラ名(def内にあるdisplaynameではない方)
trigger2 = enemy,authorname = "authorA"	;そのキャラの作者名(より確実にしたい場合)
trigger3 = enemy,name = "nameB"
trigger3 = enemy,authorname = "authorB"
...

２．対応したいキャラの [Statedef -2] 以下に下の記述を追加してください。

;---------------------------------------------------------------------------
;Bストーン対応
[State -2]
type = PowerAdd
triggerall = numenemy
triggerall = enemy,authorname = "Songfu"
triggerall = enemy,var(36)/10%10 = 1
triggerall = enemy,var(34)/10000 > 0
trigger1 = !numpartner
trigger2 = numpartner
trigger2 = ID < partner,ID
value = 10*(enemy,var(34)/10000)

[State -2]
type = PowerAdd
triggerall = numenemy = 2
triggerall = enemy(1),authorname = "Songfu"
triggerall = enemy(1),var(36)/10%10 = 1
triggerall = enemy(1),var(34)/10000 > 0
trigger1 = !numpartner
trigger2 = numpartner
trigger2 = ID < partner,ID
value = 10*(enemy(1),var(34)/10000)
