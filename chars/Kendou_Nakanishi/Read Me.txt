ボタン配置
--------------------------------------------------------------------------------
A = 弱攻撃
B = 中攻撃
C = 強攻撃
Z = Bアクションボタン
X = チャージボタン
Y = エンハンスボタン
START = 現在未使用

なお、CAPCOM配列にしたい方(ようはCAPCOMやSNKキャラと戦いたい方)は
CMDの一番上にある[Remap]の部分の;を全て外してください
ちなみに、外すと

X = 弱攻撃
Y = 中攻撃
B = 強攻撃
A = Bアクションボタン
Z = チャージボタン
C = エンハンスボタン
START = 現在未使用

というボタン配置になります

なお、人によっては中攻撃を下に持って行きたい方もいるでしょうから
そういう場合はCMDの二番目にある[Remap]の部分の;を全て外してください
ちなみに、外すと

X = 弱攻撃
A = 中攻撃
B = 強攻撃
Y = Bアクションボタン
Z = チャージボタン
C = エンハンスボタン
START = 現在未使用

というボタン配置になります

その他のボタン配置にしたい方は３番目を自分で弄ってください

--------------------------------------------------------------------------------
AIについて
--------------------------------------------------------------------------------
AIはCnsフォルダにあるsystem_modeを弄れば変える事ができます
また、中西流・強打～勝利の一撃～のクリーンヒット率を設定する事ができます
(デフォルトではAIはNo AIに、のクリーンヒット率は10に設定されています)

また、最初からAIが入った状態で、戦闘を開始したい場合は
Cnsフォルダ内のsystem_modeを弄ってください

--------------------------------------------------------------------------------
使用可能システム
--------------------------------------------------------------------------------
投げ　　　　　　　　　  投げは投げ
                        地上で横を押しながら強攻撃で出せる
                        若干、発生が遅いが、見てからの回避は厳しい
                        失敗しても、横入力強攻撃が出るので安心

フィジカルゲージ        略してＰゲージ
　　　　　　　　　　　　強攻撃や必殺技、投げなどを使用すると減っていき、ゲージが無くなると技が出せなくなる
                        なお、ライフが減っているとその分、Ｐゲージの最大値が増える
                        ちなみに、時間の他、チャージ、アドバンスドチャージ、エクステンドチャージなどでも回復する

Ｂダッシュ              攻撃の隙をキャンセルして行うダッシュ
　　　　　　　　　　　　地上ではＮor横or下＋Ｂ、空中はＮor横or上or下＋Ｂで出せる
                        １ゲージ消費。コンボのお供にどうぞ
                        ちょっと昔に流行った曲名じゃないよ

Ｂカウンター            ガード中に反撃できる技
　　　　　　　　　　　　地上ガード時に横＋Ｂで１ゲージ消費で出せる
                        ただし、相手に読まれるとＢダッシュに化けるので注意

Ｂエスケープ            喰らっている最中に脱出できる技
　　　　　　　　　　　　横＋Ｂで４ゲージ消費で出せる
                        ゲージ消費量が多いので使いどころは要注意

チャージ                Ｐゲージを回復させる手段の一つ
                        押しっぱなしにするコトで持続し、一定時間経過後から徐々にＰゲージが回復し始める
                        そのため、こまめにやってもあまり意味がない
　　　　　　　　　　　　相手をダウンさせた後などに使うのがベスト

アドバンスドチャージ　　Ｐゲージを回復させる手段
                        下２回とチャージボタンで使用可能
                        １ゲージを消費するが、いきなり多くのゲージを回復できる他
　　　　　　　　　　　　チャージと違い、押しっぱなしにしていた場合、即ゲージを回復し始める

エクステンドチャージ    Ｐゲージを回復させる手段
                        チャージもしくはアドバンスドチャージ中にチャージボタン押しっぱなしで十字キーを一回転させる
                        チャージの２倍のＰゲージを回復する他、攻撃力も上がっていく
                        ただし、その代償としてライフがどんどん減っていく
                        
エンハンス　            三回だけ使用できるキャラ特有の動作
　　　　　　　　　　　　BBBでは弓道のPゲージ消費量低下ですが、この剣道は
　　　　　　　　　　　　次のコンボの攻撃力が２倍になるが、効果発揮前にダメージを受けた場合、
                        次のコンボで受けるダメージも1.5倍になるというものにしています
　　　　　　　　　　　　なお、重ねがけしても効果は重複しないので、効果が切れる度に使用し直さなくてはいけません
                        
振り向き攻撃            相手を飛び越した状態(相手に背を向けている状態)で２段ジャンプ前なら
                        上押しながら攻撃ボタンで相手の方へ落下しつつ攻撃する
                        タイミングは若干シビアだが、なかなかに強いので慣れると良いかも

--------------------------------------------------------------------------------
使用可能必殺技＆簡単な性能説明
--------------------------------------------------------------------------------

中西流・衝打      　↓＼→＋弱ｏｒ中ｏｒ強ボタン
         
                　　一定時間で消滅する地を這う飛び道具を放つ
                　　ボタンによって、使用後の硬直、Ｐゲージ消費量、ダメージ、移動距離が異なる
                　　密着で弱版をガードさせると備有利なので、固めに使用するのもありかも
　　　　　　　  　　相手との距離や相手の次の行動を考えて使っていこう

中西流・強突      　↓／←＋弱ボタン

　　 　　　　　 　　振りかぶってから攻撃する技
                　　タメが可能で、タメた時間によって４段階に性能が変化する
                  　１段目は全ガード可能、２段目は空中ガード不能かつヒット時はバウンド
                  　３段目は立ちガードのみ可能でヒット時は２段目より高くバウンド
                  　４段目はガード不能かつヒット時は３段目と同じバウンド
                  　崩しに使えなくもないがタメ時間が長いので、暴れに弱い

中西流・虚手　　　　↓／←＋中ボタン

　　 　　　　　 　　一定時間経過後に使用した場所に攻撃判定が発生する所謂設置技
                  　相手が近寄っても発生するので、前もっておいておくのも悪くない
                  　強打とモーションがまったく同じだが、攻撃判定は存在しない
                　　タメが可能で、タメた時間によって発生するまで時間が変化する
                  　また、３段目と４段目はヒット時は受け身不可能
                  　強打とこれを利用して、相手に攻め込ませないようにする立ち回りができるかも？

中西流・正打      　↓／←＋強ボタン

　　 　　　　　 　　大きく構えてから攻撃する技
                　　ヒット時は高くバウンドするが、発生はかなり遅く、全ガードも可能
                  　ただし、構えのモーションにはアーマーがついている
　　　　　　　　　　アーマーで相手の攻撃を受けると技の性能が変化
　　　　　　　　　　ダメージの増加するだけでなく、発生が早くなり、攻撃判定発生まで無敵がつく
                  　ただし、構えに入る前はアーマーは存在し無いし、攻撃判定発生後は無敵も無いので多段技に弱い
                  　相手の行動を読むセンスが必要

中西流・昇り胴    　→↓＼＋弱ｏｒ中or空中で強ボタン(空中可)

　　　　　　　　　　対空技っぽいが無敵は無い
　　　　　　　　　　弱及び空中版その場で飛び上がってから攻撃する
                  　空中版は押したボタンによって飛び上がる高さが違う
             　   　中地上版は一定距離前進した後に飛び上がる
　　　　　　　　　　前進部分にも攻撃判定があり、連続ヒットする
                  　コンボの中心になると思われる技

中西流・昇り胴虚  　→↓＼＋強ボタン

　　　　　　　　　　中地上版昇り胴と同じように突進するもその後飛び上がらない
　                　ただ、ヒットガード問わず当てて不利なので使い道は少ない
                  　ただ、強ボタン押しっぱなしで攻撃判定が発生しなくなる
                  　コンボだと思った相手に対してフェイント的使い方が可能？

昇り胴・弐の太刀  　中西流・昇り胴中(空中にいる時)に弱ｏｒ中or強ボタン

　　　　　　　　　　昇り胴から派生技
　　　　　　　　　　昇り胴空振り時も使用でき、押したボタンによって出る攻撃が変わる
　　　　　　　　　　弱版は相手を打ち上げ、中版は相手を吹き飛ばし、強版は相手を叩きつける
                  　押したボタンにその後の状況が変わるので、色々と考える必要がある

--------------------------------------------------------------------------------
使用可能Ｂパワーアーツ説明
--------------------------------------------------------------------------------
中西流・衝打～必勝の打ち筋～      ↓＼→＋Ｂアクションボタン
         
                　　　　　　　　　強化版中西流・衝打のを放つ
                　　　　　　　　　硬直が極端に少なく、ヒット時は中距離ならダッシュしてから攻撃を連続ヒットさせられる
                　　　　　　　　　また、移動距離と持続時間も通常版より長い
　　　　　　　  　　　　　　　　　相手を固める時に使用するのも悪くないかも？

中西流・面～打突の極み～          ↓／←＋Ｂアクションボタン

                                  正打と似たようなモーションで攻撃する技
                　　　　　　　　　剣道の使える技で唯一発生と同時に無敵があるため、切り返しに使える
                　　　　　　　　　ただ、隙は正打と同じぐらい大きいので、ガードされたら反確なのに注意

中西流・強打～突破の一撃～　　　  中西流・強突のタメ中(一定時間溜める必要あり)に弱ボタンを離さずに↓／←＋Ｂアクションボタン

                                  強突の強化版とも言える技
                                  ガード不能かつ、暗転後発生は１フレ、さらにバウンドまでする
                                  威力も上がっているので、最大近くまでタメていて、ゲージがあるなら使うのも良い
                                  ただ、無敵時間がある訳でもないので暗転後に潰される可能性はあるので注意

中西流・昇り胴～特訓の成果～　　　→↓＼＋Ｂアクションボタン(空中可)

 　　　　　　　　　　　　　　　　 中西流・昇り胴の強化技
                                  地上版は地上中版中西流・昇り胴と似たモーションで、地上攻撃部分が多段ヒットする
                                  空中版版は中西流・昇り胴と弱版弐の太刀を連続で使用し、昇り胴部分が多段ヒットする
                                  地上版は受け身不能なのを利用してコンボダメの底上げに使ったりできる
                                  空中版はエリアルの締めなどに使えるが、ダウンは取れなくなるので注意

中西流・強打～勝利の一撃～　　　　中西流・昇り胴～特訓の成果～中(地上にいる時)に→↓＼＋Ｂアクションボタン(空中可)

                                  ２ゲージ消費して乱舞に移行する
                                  強突→立ち強→立ち中→立ち前強→空中下強→しゃがみ強と連続で繰り出す
                                  しゃがみ強後は面を繰り出し、打ち上げた相手に追撃する
                                  面による追撃はＢアクションボタン押しっぱなしで溜める事ができる
                                  ボタンを離すタイミングによって、与えるダメージなどが違う
                                  ジャストタイミングだと特大ダメージかつ、相手はバウンドし、追撃可能
                                  ジャストが決まれば殆どの相手をＫＯするので、一発逆転を狙いたい人にはオススメ

--------------------------------------------------------------------------------
アレンジ要素説明
--------------------------------------------------------------------------------
原作の剣道は強攻撃は弓道を動かしますが、この剣道は弓道がそもそもいないので
普通に強攻撃が出るようになってます

以下、原作との変更点(簡略版)

前弱をしゃがみ中に変更。それに伴い、しゃがみ中はしゃがみ強に変更
投げを前強に変更。それに伴い、前中を前強に変更
立ち強の追加
空中強の追加
空中下中を空中下強に変更。及び、使用時、慣性を維持したまま落下するように
投げにダメージの追加
投げる方向を反対に(前投げで後ろに、後ろ投げで前に投げる)
エンハンスの効果変更(上記参照)
必殺技全般の変更(上記参照)
